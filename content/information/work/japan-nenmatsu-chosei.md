每年 11 月中到 12 月初，日本公司的人事會發下幾張表格，要求在幾天內填好交回。這就是**年末調整（ねんまつちょうせい）**。

很多在日本工作的台灣人第一年都是看不懂就隨便勾，結果多繳了稅。這篇說明年末調整在算什麼、三張表各自要填什麼、外國人特別用得到的扣除項目。

---

## 一、年末調整在算什麼

日本公司每個月從薪水預扣的所得稅（**源泉徴収**）是用簡化的表格估算的，沒有考慮你的保險費、扶養家人、配偶的收入。

年末調整就是年底的一次結算：

> 一年實際該繳的稅額 － 已經預扣的總額 ＝ 退稅（或補扣）

| 日文 | 讀音 | 意思 |
|------|------|------|
| 年末調整 | ねんまつちょうせい | 年末調整 |
| 源泉徴収 | げんせんちょうしゅう | 從薪水預扣所得稅 |
| 源泉徴収票 | げんせんちょうしゅうひょう | 扣繳憑單 |
| 所得控除 | しょとくこうじょ | 所得扣除 |
| 還付 | かんぷ | 退稅 |
| 追徴 | ついちょう | 補扣 |
| 確定申告 | かくていしんこく | 自行申報所得稅 |
| 扶養 | ふよう | 扶養 |
| 控除証明書 | こうじょしょうめいしょ | 扣除證明書 |

**多數人是退稅。** 金額依狀況從幾千到幾萬日圓不等，會併在 12 月或隔年 1 月的薪水裡發。

## 二、要交的三張表

| 表格 | 日文全名 | 填什麼 |
|------|------|------|
| ① 扶養控除申告書 | 給与所得者の扶養控除等（異動）申告書 | 自己與扶養親屬的基本資料 |
| ② 基礎控除・配偶者控除等申告書 | 給与所得者の基礎控除申告書 兼 配偶者控除等申告書 兼 所得金額調整控除申告書 | 自己與配偶的今年所得見込み |
| ③ 保險料控除申告書 | 給与所得者の保険料控除申告書 | 自己繳的各種保險費 |

**①其實是明年的份。** 這張表每年都在年末調整時一起發，上面寫的是「令和〇年分」——通常是**下一年度**的，用來決定明年每個月要預扣多少。同時也要確認今年那張有沒有要改的地方（結婚、生小孩、家人開始工作）。

### ① 扶養控除申告書要注意的欄位

| 欄位 | 說明 |
|------|------|
| 氏名・住所・個人番号 | 姓名、住址、個人編號（マイナンバー） |
| 世帯主との関係 | 和戶長的關係（自己就寫「本人」） |
| 源泉控除対象配偶者 | 有配偶且符合所得條件時填 |
| 控除対象扶養親族 | 16 歲以上的扶養親屬 |
| 非居住者である親族 | 住在國外的親屬要在這裡勾，並附證明文件 |
| 障害者・寡婦・ひとり親・勤労学生 | 符合的人勾選 |

### ③ 保險料控除申告書：要附證明書

這張表上寫的金額，**幾乎每一項都要附「控除証明書」正本**。10 月左右保險公司和日本年金機構會把證明書寄到家裡，收到就先收好，年末調整時要用。

| 項目 | 要不要證明書 |
|------|------|
| 生命保険料 | 要（保險公司寄的「控除証明書」） |
| 地震保険料 | 要 |
| 国民年金保険料 | 要（「社会保険料控除証明書」） |
| 国民健康保険料 | 不用，自己填一年繳的金額 |
| iDeCo（個人型確定拠出年金） | 要 |
| 小規模企業共済 | 要 |

## 三、在日外國人常用到的扣除

### 1. 留學時期自己繳的國民年金

很多人是「語言學校／大學 → 就職」，**學生時期自己繳的國民年金保險費，是當年度可以扣除的社會保險費**。入職那一年特別容易漏掉：4 月前還是學生自己繳國民年金與國民健康保險，4 月後公司幫你加入社保，前半年的那些錢也要填進去。

### 2. 匯回台灣的扶養親屬

住在國外的親屬要當扶養親屬扣除，需要兩類文件：

| 文件 | 日文 | 內容 |
|------|------|------|
| 親屬關係文件 | 親族関係書類 | 戶籍、出生證明等可證明關係的文件（附日文翻譯） |
| 匯款關係文件 | 送金関係書類 | 當年度實際匯款的紀錄（匯款單、銀行明細） |

**規定在 2023 年收緊了。** 30 歲以上未滿 70 歲的非居住親屬，原則上不能列為扣除對象，除外的情形是：留學中、身心障礙者、該年度匯款達 38 萬日圓以上。70 歲以上或 16〜29 歲的親屬，仍依原本的條件判斷。

**匯款紀錄要留整年份。** 用一次大額匯款湊 38 萬日圓也可以，但必須是當年度實際匯出、匯給該名親屬本人的紀錄。

### 3. 年中入職、年中轉職的人

今年之內換過公司的話，**要把前公司的源泉徴収票交給現在的公司**，否則年末調整算不出一整年的收入。前公司的源泉徴収票通常在離職後一個月內寄到家裡，沒收到要主動去要。

## 五、年末調整不夠，要跑確定申告的情況

| 情況 | 為什麼年末調整處理不到 |
|------|------|
| 醫療費超過一定金額（医療費控除） | 不在年末調整的範圍 |
| 故鄉納稅但不適用一站式（6 個以上自治體等） | 要自己申報捐款扣除 |
| 第一年的房貸扣除（住宅ローン控除） | 第一年一定要確定申告，第二年起才能併入年末調整 |
| 有兩份以上的薪資收入 | 只有主要那家會做年末調整 |
| 副業所得超過 20 萬日圓 | 要合併申報 |
| 年中離職、年底沒有在職 | 沒有公司幫你做 |
| 年末調整漏報了扣除項目 | 自己補報回來 |

確定申告的期間是**隔年 2 月 16 日到 3 月 15 日**，可以用 e-Tax 線上辦，也可以到稅務署。純粹是退稅的申報（還付申告），五年內都可以辦，不受那一個月的限制。

## 台灣人常卡住的地方

1. **看不懂就全部留空。** 空白等於放棄扣除，稅會多繳。看不懂就問人事，這是公司每年都在處理的事，問不會失禮。
2. **忘了學生時期自己繳的國民年金。** 入職第一年最常漏的一筆，金額不小。
3. **沒留匯款紀錄。** 想申報台灣的父母為扶養，卻只有現金帶回去或透過親友轉交，沒有銀行紀錄就無法證明。
4. **以為退稅會另外撥款。** 日本的年末調整退稅是併在薪水裡，看薪資明細的「年末調整還付金」欄位。
5. **把年末調整和住民稅混在一起。** 年末調整算的是所得稅；住民稅是依今年的所得，從隔年 6 月開始扣。今年薪水變多，明年的住民稅就會變重。
6. **沒交前公司的源泉徴収票。** 年中轉職的人漏掉這張，年末調整就算不完，公司會要求你自己確定申告。
