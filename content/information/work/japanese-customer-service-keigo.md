在日本做餐飲、便利商店、零售、飯店的接客工作，用的日文和教科書上的敬語不太一樣。它是一套**固定下來的句型**，數量不多，但要求說得一模一樣。

這也是好消息：**背熟二十幾句，一整天的班幾乎就撐得住。** 這篇照客人進門到離店的流程整理，最後再補店內溝通和出錯時的說法。

---

## 一、迎客與帶位

| 日文 | 讀音 | 意思 |
|------|------|------|
| いらっしゃいませ | いらっしゃいませ | 歡迎光臨 |
| 何名様ですか | なんめいさまですか | 請問幾位 |
| お二名様でよろしいでしょうか | おふたりさまでよろしいでしょうか | 兩位是嗎 |
| ただいま満席でございます | ただいままんせきでございます | 目前客滿 |
| 少々お待ちくださいませ | しょうしょうおまちくださいませ | 請稍等 |
| お待たせいたしました | おまたせいたしました | 讓您久等了 |
| こちらへどうぞ | こちらへどうぞ | 這邊請 |
| お履物はこちらでお脱ぎください | おはきものはこちらでおぬぎください | 請在這裡脫鞋 |
| 禁煙席と喫煙席、どちらになさいますか | きんえんせきときつえんせき、どちらになさいますか | 禁菸席還是吸菸席 |

**「少々お待ちください」要加「ませ」才完整。** 接客場合說「少々お待ちくださいませ」，語氣會柔和很多；對店內同事則說「ちょっと待ってください」就夠。

## 二、點餐與確認

| 日文 | 讀音 | 意思 |
|------|------|------|
| ご注文はお決まりですか | ごちゅうもんはおきまりですか | 決定好要點什麼了嗎 |
| お決まりになりましたらお呼びください | おきまりになりましたらおよびください | 決定好請叫我 |
| ご注文を繰り返します | ごちゅうもんをくりかえします | 我重複一次您的點單 |
| 以上でよろしいでしょうか | いじょうでよろしいでしょうか | 這樣就可以了嗎 |
| かしこまりました | かしこまりました | 好的、明白了 |
| 申し訳ございません、ただいま品切れでございます | もうしわけございません、ただいましなぎれでございます | 抱歉，目前缺貨／賣完了 |
| お飲み物はいつお持ちいたしましょうか | おのみものはいつおもちいたしましょうか | 飲料什麼時候送上來 |
| お待ちどおさまでした | おまちどおさまでした | 讓您等了（送餐時） |
| 熱いのでお気をつけください | あついのでおきをつけください | 很燙請小心 |
| 失礼いたします | しつれいいたします | 不好意思（上菜、收盤子時） |

**「かしこまりました」是接客場合最標準的「好的」。** 對客人不要說「了解しました」——那是對同事或下級用的。對店長可以說「承知しました」。

## 四、別說的「バイト敬語」

以下這些說法在店裡很常聽到，但都是不正確的敬語。**面試、飯店、高級餐廳特別在意**。

| 常聽到（錯） | 正確說法 | 為什麼 |
|------|------|------|
| よろしかったでしょうか | よろしいでしょうか | 確認現在的事，不用過去式 |
| こちらハンバーグになります | こちらハンバーグでございます | 「になります」是變化，不是「是」 |
| お会計のほう、二千円です | お会計は二千円でございます | 「〜のほう」是多餘的模糊用法 |
| 了解しました | かしこまりました／承知しました | 「了解」不用於對客人、對上級 |
| 千円からお預かりします | 千円お預かりいたします | 不需要「から」 |
| ご注文の品は以上で揃いましたか | ご注文の品は以上でお揃いでしょうか | 主語是客人的東西，要用敬語 |
| 大丈夫です | 承知しました／結構でございます | 「大丈夫」過於口語，意思也模糊 |

## 五、出錯、客人抱怨時

| 日文 | 讀音 | 意思 |
|------|------|------|
| 申し訳ございません | もうしわけございません | 非常抱歉（接客最標準的道歉） |
| 大変失礼いたしました | たいへんしつれいいたしました | 非常失禮 |
| すぐに確認いたします | すぐにかくにんいたします | 我立刻確認 |
| すぐにお取り替えいたします | すぐにおとりかえいたします | 我馬上為您換 |
| 店長を呼んでまいります | てんちょうをよんでまいります | 我去請店長來 |
| お待たせして申し訳ございません | おまたせしてもうしわけございません | 抱歉讓您等這麼久 |
| 私では分かりかねますので、確認してまいります | わたしではわかりかねますので、かくにんしてまいります | 我無法判斷，我去確認 |

**順序永遠是：道歉 → 確認 → 請人。** 不要先解釋原因，也不要自己判斷能不能退費、能不能免費。遇到情緒激動的客人，說完「申し訳ございません。店長を呼んでまいります」就去找人，這是最安全也最被期待的做法。

## 六、店內溝通

| 情境 | 日文 | 讀音 | 意思 |
|------|------|------|------|
| 上班進店 | おはようございます | おはようございます | 早安（接客業不分時段都說這句） |
| 接受指示 | 承知しました | しょうちしました | 我明白了 |
| 聽不懂 | すみません、もう一度お願いできますか | すみません、もういちどおねがいできますか | 抱歉，可以再說一次嗎 |
| 不會做 | やり方を教えていただけますか | やりかたをおしえていただけますか | 可以教我怎麼做嗎 |
| 做完回報 | 〜が終わりました。次は何をしましょうか | 〜がおわりました。つぎはなにをしましょうか | 〜做完了，接下來做什麼 |
| 要離開一下 | 少し外していただいてもいいですか | すこしはずしていただいてもいいですか | 可以離開一下嗎 |
| 下班 | お先に失礼します | おさきにしつれいします | 我先下班了 |
| 送同事下班 | お疲れ様でした | おつかれさまでした | 辛苦了 |

**「〜が終わりました。次は何をしましょうか」是最受店長歡迎的一句話。** 日本的店家最怕打工的人做完事站著不動，主動報告加主動問，評價會明顯不一樣。

## 台灣人常卡住的地方

1. **聲音太小。** 接客敬語說得再標準，客人沒聽到就沒意義。「いらっしゃいませ」要讓店門口聽得到。
2. **把「了解しました」用在客人身上。** 這是最常被店長糾正的一點，對客人一律用「かしこまりました」。
3. **被抱怨時先解釋。** 中文的習慣是先說明狀況，日本的接客現場是先道歉，解釋留到之後。
4. **太少發聲。** 日本的店裡幾乎隨時在說話：上菜說「失礼いたします」、經過客人旁邊說「恐れ入ります」、收盤子說「お済みのお皿をお下げしてもよろしいでしょうか」。沉默會被當成不熟練。
5. **把敬語全部用在同事身上。** 對店長和前輩用丁寧體就夠，用到接客等級的「〜でございます」反而怪。

---

接客敬語背起來不難，難的是**客人突然問了課本上沒有的問題**，而且還要一邊接話一邊動手。
