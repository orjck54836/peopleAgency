日本的商務郵件，有一副幾乎所有公司都通用的骨架。

**收件人 → 問候 → 報上自己 → 正文 → 結尾 → 簽名**，每一段都有固定的寫法。只要骨架對了，正文就算寫得簡單，也不會失禮；骨架錯了，內容再好也會讓對方覺得怪。

這篇先拆解骨架，再整理請託、延期、催促、道歉、確認五種最常寫的郵件，最後附一封完整的延期郵件範本。

---

## 一、件名：一眼看出要做什麼

| 不好的件名 | 好的件名 |
|------|------|
| お世話になっております | 【ご相談】〇〇資料の提出日について |
| 先日の件 | 11/24（火）お打ち合わせ日程のご確認 |
| 陳です | 【至急】本日のシステム停止について |
| （空白） | 見積書送付のご案内（〇〇案件） |

規則很簡單：**件名要寫具體的事情，讓對方不打開也知道要做什麼。** 用【】標出性質（ご相談、ご依頼、ご確認、至急）是日本郵件很常見的寫法。回信時件名保留「Re:」不要刪，對方才找得到前後文。

## 二、郵件的骨架

```
株式会社△△
営業部 田中様                       ← ① 收件人

いつもお世話になっております。        ← ② 問候
〇〇株式会社の陳でございます。        ← ③ 報上自己

（正文）                            ← ④ 正文

何卒よろしくお願いいたします。        ← ⑤ 結尾

─────────────────
〇〇株式会社 営業部
陳 大文（チン ダイブン）
TEL：03-XXXX-XXXX
Mail：chen@example.co.jp
─────────────────                  ← ⑥ 簽名
```

| 段落 | 社外（客戶） | 社內（同事、主管） |
|------|------|------|
| ① 收件人 | 公司名＋部門＋姓名＋様 | 姓名＋さん（主管用職稱：佐藤部長） |
| ② 問候 | いつもお世話になっております | お疲れさまです |
| ③ 報上自己 | 〇〇株式会社の陳でございます | 営業部の陳です |
| ⑤ 結尾 | 何卒よろしくお願いいたします | よろしくお願いします |

收件人的敬稱：寄給個人用「**様**」，寄給公司或部門而不指定人時用「**御中**」（例：株式会社△△ 営業部御中）。「様」和「御中」不會同時用。

## 三、五種最常寫的郵件

### 1. 請託（依頼）

| 日文 | 意思 |
|------|------|
| 〇〇についてお願いがあり、ご連絡いたしました | 關於〇〇有事想拜託，所以跟您聯絡 |
| お手数をおかけしますが、〇〇をご確認いただけますでしょうか | 麻煩您了，可以請您確認〇〇嗎 |
| 〇日までにご返信いただけますと幸いです | 如果能在〇日前回覆就太好了 |
| ご多忙のところ恐縮ですが、よろしくお願いいたします | 百忙之中不好意思，麻煩您了 |

**請託一定要寫期限。** 「お手すきの際に」（有空的時候）聽起來客氣，但對方可能真的一直沒空。寫「〇日までに」再加「幸いです」，既有禮又清楚。

### 2. 延期（延期のお願い）

| 日文 | 意思 |
|------|------|
| 大変申し訳ございませんが、〇〇の提出を〇日まで延期させていただけないでしょうか | 非常抱歉，可以讓我們把〇〇的提交延到〇日嗎 |
| 〇〇の確認に想定以上の時間を要しておりまして | 因為〇〇的確認比預期花了更多時間 |
| ご迷惑をおかけし、誠に申し訳ございません | 造成您的困擾，實在非常抱歉 |
| 〇日には必ずお送りいたします | 〇日一定會寄給您 |

延期的郵件要寫齊四件事：**道歉、新的日期、原因（簡短）、一定做得到的承諾**。原因不需要寫很長，寫太長反而像在找藉口。

### 3. 催促（催促）

| 日文 | 意思 |
|------|------|
| 先日お送りした〇〇の件ですが、その後いかがでしょうか | 關於前幾天寄給您的〇〇，後來情況如何呢 |
| 行き違いでしたら申し訳ございません | 如果已經寄出而錯過了，非常抱歉 |
| 恐れ入りますが、〇日までにご回答いただけますでしょうか | 不好意思，可以請您在〇日前回覆嗎 |

日本的催促郵件**不直接寫「你還沒回」**，而是用「その後いかがでしょうか」（後來怎麼樣了）來問。「行き違いでしたら」（如果剛好錯過）是留給對方台階的固定句。

### 4. 道歉（お詫び）

| 日文 | 意思 |
|------|------|
| この度は、〇〇の件でご迷惑をおかけし、誠に申し訳ございません | 這次因為〇〇的事造成您的困擾，實在非常抱歉 |
| 確認が不十分だったことが原因です | 原因是確認不夠充分 |
| 今後は〇〇を徹底し、再発防止に努めます | 今後會徹底〇〇，努力防止再次發生 |
| 取り急ぎ、メールにてお詫び申し上げます | 先用郵件向您致歉 |

道歉郵件的順序是 **道歉 → 原因 → 對策 → 再道歉**。重大的失誤，郵件之後通常還要打電話或當面道歉，「取り急ぎメールにて」就是表示「先用郵件，之後會再正式處理」。

### 5. 確認（確認）

| 日文 | 意思 |
|------|------|
| 本日はお電話ありがとうございました | 謝謝您今天的來電 |
| お電話でお話しした内容を、念のためお送りいたします | 保險起見，把電話中談到的內容寄給您 |
| 日時：11 月 24 日（火）16:00〜17:00 | 日期時間：11 月 24 日（週二）16:00〜17:00 |
| 認識に相違がございましたら、ご指摘いただけますと幸いです | 如果理解有出入，請不吝指正 |

**電話或會議決定的事，用郵件再確認一次**，是日本職場的習慣。日期、時間、地點、出席者用條列寫，比寫成一段文字清楚。

## 四、完整範本：跟客戶延期

```
件名：【ご相談】〇〇資料のご提出日について

株式会社△△
営業部 田中様

いつもお世話になっております。
〇〇株式会社の陳でございます。

11 月 20 日（金）にご提出予定でした〇〇資料について、
大変申し訳ございませんが、
11 月 24 日（火）まで延期させていただけないでしょうか。

データの確認に想定以上の時間を要しており、
現在、全体の八割ほどまで進んでおります。
24 日の午前中には必ずお送りいたします。

ご迷惑をおかけし、誠に申し訳ございません。
ご検討のほど、何卒よろしくお願いいたします。

─────────────────
〇〇株式会社 営業部
陳 大文
TEL：03-XXXX-XXXX
─────────────────
```

**延期的郵件越早寄越好。** 交期當天才寄，對方已經沒有調整的空間；提前兩三天說，對方還能重新安排。

## 五、郵件與聊天工具的差別

越來越多日本公司在社內用 Slack、Teams、Chatwork 溝通，語氣和郵件不一樣：

| | 郵件（社外） | 聊天工具（社內） |
|------|------|------|
| 開頭 | いつもお世話になっております | お疲れさまです（也常省略） |
| 收件人 | 公司＋部門＋姓名＋様 | @姓名＋さん |
| 結尾 | 何卒よろしくお願いいたします | よろしくお願いします |
| 長度 | 一封寫完整件事 | 短句、分幾則 |
| 簽名 | 要 | 不用 |

聊天工具輕鬆一點沒關係，但**結論先講**的原則不變。報告、請託時，第一行寫「【ご報告】」「【ご相談】」，主管看通知就知道要不要馬上處理。

## 六、外國人最常犯的五個錯

1. **社外郵件寫「お疲れさまです」。** 那是社內用的。給客戶一律「お世話になっております」。
2. **「〇〇様各位」「〇〇御中様」。** 「各位」本身就是敬稱，「御中」和「様」不同時用。
3. **「ご苦労さまです」寫給主管或客戶。** 這句是上對下用的，對上一律用「お疲れさまです」。
4. **一封郵件塞好幾件事。** 不同的事分開寄，件名才能寫清楚，對方回信也不會漏。
5. **CC 的人沒寫在收件人欄。** 有 CC 時，收件人欄寫「（CC：佐藤様）」之類，讓對方知道還有誰收到。

## 常見問題

**Q：一定要寫「いつもお世話になっております」嗎？第一次聯絡的對象也這樣寫？**
A：第一次聯絡的對象，改用「突然のご連絡失礼いたします」（突然聯絡您，不好意思）或「初めてご連絡いたします」（初次聯絡您）。往來過一次之後，就用「いつもお世話になっております」。

**Q：回信要多快？**
A：一般建議當天、最晚隔天回。需要時間確認的事，先回一封「確認のうえ、〇日までにご連絡いたします」（確認後會在〇日前回覆），讓對方知道你收到了。

**Q：可以用翻譯軟體寫嗎？**
A：可以當草稿，但一定要自己檢查敬語和固定句型。翻譯軟體常把社內和社外的語氣混在一起，也會漏掉「様」「御中」這類日本特有的規則。

**Q：郵件裡可以用表情符號或「！」嗎？**
A：社外郵件不用。社內聊天工具依公司文化，有些團隊很常用，先觀察同事怎麼寫再跟著用。
