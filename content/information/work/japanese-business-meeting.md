  - q: "日本的會議為什麼很少有人當場反對？"
    a: "很多日本公司在會議前就會先私下溝通、取得共識，這叫「根回し（ねまわし）」。會議比較像是正式確認，而不是討論的場合。有不同意見的話，最好在會議前先找相關的人商量，會議上則用「懸念があります」（有一點疑慮）這類委婉的說法提出。"

    a: "日本公司的議事錄通常包含日期時間、出席者、議題、決定事項、待辦事項（誰、做什麼、什麼時候前）。重點是「決定了什麼」和「接下來誰要做什麼」，不用逐字記錄每個人說的話。會後當天寄給出席者確認是常見的做法。"

在日本公司工作，每週都會有好幾場會議。台灣人最常遇到的狀況是：**聽得懂大概，但不知道什麼時候該開口**，等想好要說什麼，話題已經換了。

日本的會議有固定的流程和說法，開場、報告、提意見、反對、總結，每一段都有幾句常用的句型。**先把句型背熟，臨場只要換掉內容就好**。

這篇照會議的流程整理，用一場「討論新產品上市時程」的會議當例子。

---

## 一、先看懂這些字

| 日文 | 讀音 | 意思 |
|------|------|------|
| 会議 | かいぎ | 會議 |
| 打ち合わせ | うちあわせ | 討論、碰面（比較小型的會議） |
| 議題 | ぎだい | 議題 |
| 資料 | しりょう | 資料 |
| 議事録 | ぎじろく | 會議記錄 |
| 進行役／司会 | しんこうやく／しかい | 主持人 |
| 決定事項 | けっていじこう | 決定事項 |
| 宿題／持ち帰り | しゅくだい／もちかえり | 待辦（帶回去處理的事） |
| 根回し | ねまわし | 會前溝通 |
| 認識合わせ | にんしきあわせ | 對齊彼此的理解 |
| 懸念 | けねん | 疑慮 |
| 合意 | ごうい | 共識 |

**「持ち帰って検討します」是很常聽到的一句**，意思是「帶回去研究」，代表這次不會當場決定。

## 二、日本會議的流程

| 階段 | 做什麼 |
|------|------|
| 會前 | 寄出議題和資料，和相關的人做根回し |
| 開場 | 主持人說明目的、議題、結束時間 |
| 報告 | 各負責人報告進度 |
| 討論 | 提出意見、問題、疑慮 |
| 總結 | 確認決定事項和待辦事項 |
| 會後 | 寄出議事錄 |

**會議前的準備比會議本身重要。** 被指定要報告的話，資料最好在前一天寄出，讓大家先看過。

## 三、開場與主持

| 日文 | 讀音 | 意思 |
|------|------|------|
| お時間になりましたので、始めさせていただきます | おじかんになりましたので、はじめさせていただきます | 時間到了，我們開始 |
| 本日の議題は二点です | ほんじつのぎだいはにてんです | 今天的議題有兩點 |
| 本日は〇〇について決めたいと思います | ほんじつは〇〇についてきめたいとおもいます | 今天想決定〇〇的事 |
| 十一時までを予定しております | じゅういちじまでをよていしております | 預計到十一點 |
| では、〇〇さんからお願いします | では、〇〇さんからおねがいします | 那麼，請〇〇先開始 |
| 時間が押していますので、次に進みます | じかんがおしていますので、つぎにすすみます | 時間有點超過，我們進到下一項 |

## 四、報告

| 日文 | 讀音 | 意思 |
|------|------|------|
| 〇〇の進捗についてご報告します | 〇〇のしんちょくについてごほうこくします | 我來報告〇〇的進度 |
| お手元の資料の三ページをご覧ください | おてもとのしりょうのさんページをごらんください | 請看手邊資料的第三頁 |
| 結論から申し上げますと | けつろんからもうしあげますと | 先說結論的話 |
| 現時点で、予定より一週間遅れています | げんじてんで、よていよりいっしゅうかんおくれています | 目前比預定晚一週 |
| 以上です。何かご質問はありますか | いじょうです。なにかごしつもんはありますか | 以上。有什麼問題嗎 |

報告的結構和報連相一樣：**結論 → 原因 → 對策**，詳細可以參考[日本職場的報連相](/work/information/japanese-horenso)。

## 五、發表意見與提問

| 日文 | 讀音 | 意思 |
|------|------|------|
| 一点よろしいでしょうか | いってんよろしいでしょうか | 我可以說一點嗎 |
| 私としては、A 案がいいと考えています | わたしとしては、エーあんがいいとかんがえています | 我自己認為 A 案比較好 |
| 理由は二つあります | りゆうはふたつあります | 理由有兩個 |
| 〇〇さんの意見に賛成です | 〇〇さんのいけんにさんせいです | 我贊成〇〇的意見 |
| 確認ですが、〇〇という理解でよろしいでしょうか | かくにんですが、〇〇というりかいでよろしいでしょうか | 確認一下，我理解成〇〇可以嗎 |
| 今のお話、もう少し詳しく伺えますか | いまのおはなし、もうすこしくわしくうかがえますか | 剛剛說的可以再詳細說明嗎 |
| 数字の根拠を教えていただけますか | すうじのこんきょをおしえていただけますか | 可以告訴我這個數字的依據嗎 |

**「一点よろしいでしょうか」是最好用的開口句。** 等對方說完、有一個小停頓時說，大家就會把注意力轉向你。

## 六、委婉反對

日本會議很少直接說「我反對」，而是先肯定，再提出疑慮。

| 日文 | 讀音 | 意思 |
|------|------|------|
| おっしゃることはよくわかります。ただ… | おっしゃることはよくわかります。ただ… | 您說的我很理解，只是… |
| 一つ懸念があるのですが | ひとつけねんがあるのですが | 我有一個疑慮 |
| その場合、〇〇が心配です | そのばあい、〇〇がしんぱいです | 那樣的話，我擔心〇〇 |
| 別の見方もできるかと思います | べつのみかたもできるかとおもいます | 我想也可以從別的角度看 |
| もう少し検討が必要ではないでしょうか | もうすこしけんとうがひつようではないでしょうか | 是不是需要再多研究一下 |
| 代案として、〇〇はいかがでしょうか | だいあんとして、〇〇はいかがでしょうか | 作為替代方案，〇〇如何 |

**反對的時候帶著替代方案。** 只說「不好」會被當成扯後腿，說「不如這樣做」就變成建設性的意見。

## 七、總結與確認

| 日文 | 讀音 | 意思 |
|------|------|------|
| では、本日の決定事項を確認します | では、ほんじつのけっていじこうをかくにんします | 那麼，確認今天的決定事項 |
| 〇〇さんが、金曜日までに見積もりを作成する、ということでよろしいですか | 〇〇さんが、きんようびまでにみつもりをさくせいする、ということでよろしいですか | 〇〇在週五前做好報價單，這樣可以嗎 |
| この件は持ち帰って検討します | このけんはもちかえってけんとうします | 這件事帶回去研究 |
| 次回は来週の火曜日でいかがでしょうか | じかいはらいしゅうのかようびでいかがでしょうか | 下次訂在下週二如何 |
| 議事録は本日中にお送りします | ぎじろくはほんじつちゅうにおおくりします | 會議記錄今天內寄出 |
| 本日はありがとうございました | ほんじつはありがとうございました | 今天謝謝大家 |

## 八、台灣人在日本開會最常被提醒的五件事

1. **會議上才第一次提出不同意見。** 在日本會被當成沒做根回し，讓提案的人沒面子。有意見先在會前私下講。
2. **沉默不代表同意。** 日本人沉默可能只是在思考，也可能是有疑慮但不想當場說。重要的事會後再個別確認。
3. **「検討します」不一定是正面的。** 對客戶說「前向きに検討します」（積極研究）通常有希望，單純的「検討します」有時是委婉拒絕。
4. **數字和期限要當場確認。** 聽錯一個日期，之後的工作全部會錯。用「〇〇ということでよろしいですか」複誦一次。
5. **新人也要有一句話。** 完全不發言會被認為沒參與，準備一個問題或一句確認，就能讓人知道你有在聽。
