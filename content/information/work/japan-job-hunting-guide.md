日本的求職流程和台灣差異很大，而且差的不是細節，是整套邏輯。

台灣的求職是「看你能做什麼」；日本的新卒採用是「看你是什麼樣的人」。履歷格式有固定規範、面試問題有慣用答法、時程表全國幾乎同步。**不理解這套規則，再好的能力都會在初篩被刷掉。**

---

## 一、先確認你走哪一條路

| | 新卒採用 | 中途採用 |
|------|------|------|
| 對象 | 應屆畢業生（含日本的大學、專門學校留學生） | 有工作經驗者 |
| 看什麼 | 人格特質、潛力、文化適配 | **即戰力、具體實績** |
| 時程 | 全國幾乎同步，固定週期 | 全年隨時 |
| 入職 | 多為 4 月統一入社 | 隨時 |
| 日語要求 | 通常 N2 以上 | 依職種，部分 IT 職可放寬 |

**在台灣已有工作經驗的人，絕大多數走中途採用。** 不要用新卒的方式去投中途職缺——中途採用完全不在乎你的社團經歷和「學生時代最努力的事」，只看你做過什麼、做出什麼結果。

## 二、新卒採用的時程（如果你在日本念書）

日本新卒採用有一套近乎全國同步的節奏：

| 時期 | 階段 |
|------|------|
| 畢業前 1 年半～1 年（大三暑假前後） | 實習（インターン）、自我分析、業界研究 |
| 畢業前 1 年（3 月） | 企業廣報開始，說明會密集、開始投遞 ES |
| 畢業前 9 個月（6 月） | 選考開始，面試密集期 |
| 畢業前 6 個月（10 月） | **內定式**，正式確認錄用 |
| 畢業當年 4 月 | 入社 |

※ 時程為業界慣例，各企業（尤其外資與新創）可能自有節奏。

**留學生最常犯的錯是太晚開始。** 等到畢業前半年才開始找，主要企業的新卒名額已經結束了。如果你在日本念專門學校或大學，**入學第一年就該開始關注時程**。

另外，日本的新卒採用高度集中在東京。住在其他城市的人要把跑說明會與面試的交通住宿費算進預算。

## 三、履歷書（履歴書）：格式比內容更容易出錯

日本的履歷書有固定格式（JIS 規格為常見基準），自由發揮反而是扣分。

| 欄位 | 規則與地雷 |
|------|------|
| 照片 | 正式證件照、西裝、白底。**不要用生活照或修圖過度的照片** |
| 日期 | 使用和曆或西曆須全篇一致 |
| 學歷・職歷 | **由舊到新**（和台灣相反），不可留空白期間不說明 |
| 志望動機 | 要寫「為什麼是這家公司」，不是「為什麼想來日本」 |
| 自己 PR | 具體事例＋結果，避免形容詞堆疊 |
| 書寫 | 手寫仍常見於傳統企業；**不可使用修正液**，寫錯就重寫 |

**最容易被忽略的一條：學歷職歷要由舊到新排序。** 台灣習慣最新的放最前面，在日本會被視為格式錯誤。

**第二個地雷：志望動機寫成「我喜歡日本文化」。** 招募方要看的是你為什麼選這家公司、為什麼這家公司需要你。喜歡日本是前提，不是理由。

## 四、職務經歷書（職務経歴書）：中途採用的主戰場

這份文件在台灣沒有完全對應的東西。它比履歷書長得多，是中途採用的核心。

### 結構

```
1. 職務要約（3～5 行總結你的經歷）
2. 職務經歷（依公司，由新到舊或由舊到新，全篇一致）
   - 公司概要（業種、規模、員工數）
   - 所屬部門與職位
   - 具體業務內容
   - 實績（數字）
3. 活かせる経験・知識・スキル（可發揮的經驗與技能）
4. 資格・語学力
5. 自己PR
```

### 寫法的關鍵：數字

| 不好的寫法 | 好的寫法 |
|------|------|
| 負責業務開發 | 負責台灣市場新客開發，年間新增客戶 24 家，營收貢獻 1,200 萬台幣（較前年 +35%） |
| 參與系統開發 | 以後端工程師參與電商系統改版，負責訂單模組，將結帳失敗率由 3.2% 降至 0.8% |
| 擅長溝通協調 | 擔任台日兩地開發團隊的橋樑，每週主持雙語進度會議，交付延遲由平均 2 週縮短至 3 天 |

**日本企業在中途採用上非常重視可驗證的具體性。** 「擅長溝通」「積極主動」這類形容詞不會加分，寫出做了什麼、改變了什麼數字才會。

### 台灣人最大的優勢要寫在明顯的位置

中文母語能力、台日兩地的工作經驗、跨文化協作經驗——**這些不是附註，是你的核心競爭力**。尤其是有意經營台灣或華語市場的日本企業，這正是他們徵才的理由。要放在職務要約和自己 PR 裡，不要埋在最後的語学力欄位。

## 五、面試：慣用問題與背後在問什麼

| 問題 | 他們真正想知道的 |
|------|------|
| 自己紹介をお願いします | 能不能在 1～2 分鐘內有條理地講清楚自己 |
| 志望動機は？ | 為什麼是這家公司，不是這個業界、不是日本 |
| なぜ日本で働きたいのですか | 你會不會做兩年就回台灣（他們最大的顧慮） |
| 長所と短所 | 短處要能講出改善作法，不要講「我太認真」 |
| 5年後のキャリアプラン | 你的規劃和公司能提供的路徑是否一致 |
| 何か質問はありますか | **一定要問**，沒問題等於沒興趣 |

### 三個必須準備的日本式答案

**1. 「為什麼想在日本工作」要有能長期留下的理由。**
日本企業（尤其傳統企業）最怕訓練你兩年就走人。要能說明為什麼是長期選擇，而不是一時嚮往。

**2. 「為什麼是這家公司」要做過功課。**
提到該公司的具體事業、產品、近期動向。查得到的事情講不出來，就是沒做功課。

**3. 逆質問要問出層次。**
「加班多嗎」「薪水多少」不是不能問，但不該是第一個問題。問「這個職位在前三個月最大的挑戰是什麼」「團隊目前最想解決的問題是什麼」會留下完全不同的印象。

### 禮節：形式比你想的重要

入室敬禮、名片收受方式、坐姿、敬語的使用——日本面試會把這些當成「能不能派到客戶面前」的判斷依據。**不是在挑你毛病，是在評估你能不能代表公司。** 練過一次就不會慌。

線上面試同樣適用：背景整潔、準時入場（**提早 5 分鐘**）、正式服裝。

## 六、內定之後：別忘了簽證

拿到內定不等於可以上班。流程是：

```
內定 → 公司提供雇用契約與相關資料
     → 申請在留資格認定證明書（海外申請）
       或在留資格變更許可（已在日本者）
     → 審查約 1～3 個月
     → 取得後辦簽證／領新在留卡 → 入境或繼續居留 → 入社
```

**兩個時間地雷**：

1. **在日本的留學生**：在留資格變更必須在留學在留期間屆滿前完成。畢業後才開始找工作，很容易撞上期限。
2. **從台灣直接應徵**：COE 審查要 1～3 個月，所以「下個月就能到職」通常不現實。面試時要誠實說明可到職時間，這不會扣分，說不清楚才會。

另外，**職務內容必須和申請的在留資格一致**。被錄用為工程師卻實際做現場作業，更新在留時會出問題。看雇用契約時要確認職務內容寫得清楚。

## 七、台灣人最常踩的五個地雷

1. **履歷學歷職歷排序寫成由新到舊。** 格式錯誤，第一關就被扣分。
2. **志望動機停在「喜歡日本」。** 要講為什麼是這家公司。
3. **職務經歷書只寫職責、沒寫成果。** 中途採用只看結果。
4. **把中文能力當附註。** 那是你最強的差異化，要寫在前面。
5. **太晚開始。** 新卒要提前一年，中途要算進 1～3 個月的簽證審查期。

## 常見問題

**Q：日語要多好才能在日本找到工作？**
A：白領職缺多數要求 N2 以上，N1 選擇明顯更多。部分 IT 職、或以英文為工作語言的外資，可放寬到 N3 甚至不要求日語，但這類職缺總量不多。

**Q：可以從台灣直接應徵日本的工作嗎？**
A：可以，近年線上面試已很普遍。但要注意 COE 審查需 1～3 個月，而且部分企業偏好已在日本的候選人（面試方便、適應風險低）。

**Q：沒有日本的學歷，劣勢大嗎？**
A：新卒採用劣勢較大（制度本身就是為日本在校生設計的）。但中途採用看的是實務經驗，台灣的工作經驗同樣被認可，尤其是有台日業務需求的職種。

**Q：履歷一定要手寫嗎？**
A：傳統企業仍有偏好，但電子檔已被廣泛接受，外資與 IT 業幾乎都用電子檔。依企業指示為準。

**Q：轉職會被負面看待嗎？**
A：日本對轉職的看法已明顯鬆動，但**短期內頻繁轉職**仍會被追問原因。準備好一致、正面的說法（為了什麼而移動，不是為了逃離什麼）。
