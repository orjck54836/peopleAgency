特定技能是日本為了填補人力短缺而在近年建立的在留資格，對很多人來說是**最現實的赴日工作路徑**——因為它不要求大學學歷。

但它也有兩個必須在決定前就想清楚的限制：**一號有五年上限，而且不能帶家人。**

這篇把制度、考試、薪資與長期規劃一次講清楚。

---

## 一、特定技能和其他制度的差別

| | 技能實習 | **特定技能一號** | 技術・人文知識・國際業務 |
|------|------|------|------|
| 制度目的 | 技能移轉（名義上是研修） | **補充人力（正式工作）** | 專業職雇用 |
| 學歷 | 不要求 | **不要求** | 大學／專門學校畢業 |
| 日語 | 多數不要求 | **N4 或 JFT-Basic** |（無硬性規定，實務多要 N2） |
| **轉職** | 原則不可 | **同職種內可轉職** | 可 |
| 在留上限 | 依類別 | **通算 5 年** | 無上限 |
| 帶家人 | 不可 | **不可** | 可 |

**最關鍵的差別是轉職自由。** 技能實習原則上不能換雇主，這也是過去最多爭議的地方；特定技能在同一職種內可以轉職，遇到不合理的職場有退路。這是選擇制度時很重要的一點。

---

## 二、開放的產業類別

特定技能開放的產業涵蓋介護、外食業、建設、農業、漁業・養殖、飲食料品製造、素材／產業機械／電氣電子等製造業、宿泊、造船・舶用工業、汽車維修、航空、以及近年陸續增列的運輸、林業、木材產業等領域。

**制度上開放的類別曾多次增列與整併，實際清單請以出入國在留管理廳當年度公告為準。** 這是這項制度變動最頻繁的部分，也是最容易看到過期資訊的地方——網路上寫「12 個產業」「14 個產業」的文章，往往只是寫作當時的數字。

### 選職種時真正該問的問題

不是「哪個產業最好賺」，而是這三個：

1. **這個職種有沒有開放二號？** 沒有的話，你的在留就有五年天花板。
2. **技能測驗在台灣考得到嗎，還是必須到日本或第三國？**
3. **這個職種的實際工作型態我撐得住嗎？** 介護、建設、農業的體力與作息負擔差異很大。

第一個問題決定你的長期規劃，第三個決定你撐不撐得過第一年。

## 三、一號與二號：最重要的一張表

| | 特定技能一號 | **特定技能二號** |
|------|------|------|
| 在留期間 | **通算 5 年上限** | **可反覆更新，無上限** |
| 帶配偶子女 | **不可** | **可** |
| 通往永住 | 原則不計入 | **可累積** |
| 技能水準 | 具即戰力的一般程度 | **熟練技能** |
| 日語要求 | N4 或 JFT-Basic | 依產業，實務要求更高 |
| 開放產業 | 較多 | **較少**（制度上陸續擴大） |
| 支援計畫 | 須有登錄支援機關或企業的生活支援 | 不要求 |

**實務上的意義：一號是入場券，二號才是居留權。**

如果你的目標只是赴日工作幾年、累積資金與經驗就回台灣，一號本身就夠了。但如果你想長住日本、把家人帶過去、最終申請永住，**從第一天就要把路線設定成「一號 → 二號」**，包括選一個有開放二號的職種、在工作中累積足以通過二號考核的熟練度。

五年之後才開始想這件事，就來不及了。

## 四、要通過哪些測驗

特定技能一號需要**日語**與**技能**兩項測驗。

### 1. 日語測驗（兩種任一）

| 測驗 | 說明 |
|------|------|
| **JLPT N4 以上** | 一年兩次（7 月、12 月），台灣可考 |
| **JFT-Basic（國際交流基金日本語基礎測驗）** | 電腦測驗，舉辦場次較頻繁，較有彈性 |

※ 介護職種另需「介護日本語評價測驗」。

**實務建議**：如果你已經在準備日檢，直接拿 N4 最省事。如果想盡快取得資格，JFT-Basic 的場次較多、不必等半年一次的日檢。

### 2. 技能評量測驗

各職種有各自的測驗與實施機構，內容包含學科與實技。考試地點依職種與年度而異，有些在台灣或東南亞國家舉辦，有些必須到日本考。

**這是整個流程裡最需要先查清楚的一步**——報名時程、舉辦地點、一年幾場，各職種差異很大，排錯就得等下一場。

### 免測驗的例外

完成技能實習二號的人，通常可免除日語與技能測驗，直接轉特定技能一號（須同一或相關職種）。有技能實習經歷的人，這是最順的銜接路徑。

## 五、薪資與實際收入

| 職種類別 | 常見月薪範圍（稅前） |
|------|------|
| 製造業・飲食料品製造 | 約 18～24 萬日圓 |
| 外食業・宿泊 | 約 18～23 萬日圓 |
| 介護 | 約 19～25 萬日圓 |
| 建設 | 約 20～28 萬日圓（依地區與工種差異大） |
| 農業・漁業 | 約 17～22 萬日圓 |

※ 概略區間，依地區、企業規模、加班時數差異很大。東京及三大都市圈普遍高於地方。

### 法定保障：薪資必須與日本人同等以上

這是制度明文要求，不是慣例。**如果雇主開出的條件明顯低於同職位的日本人，申請本身就不會通過。**

遇到「先給低薪、之後再調」「扣宿舍費後實領很少」這類提案，要特別留意。合約上的月薪、扣除項目（住宿、水電、社會保險）、加班費計算方式，都要在簽約前一項項看清楚。

### 扣除後的實領

從稅前月薪 20 萬日圓概算：

| 項目 | 概算 |
|------|------|
| 所得稅・住民稅 | 約 1～1.5 萬日圓 |
| 社會保險（健保・年金） | 約 2.8～3.2 萬日圓 |
| 宿舍費（若由公司提供） | 約 2～4 萬日圓 |
| **實領概算** | **約 11.5～14 萬日圓** |

扣除生活費後，**每月可存 5～8 萬日圓是較現實的預期**。網路上常見的「月入 20 萬日圓」是稅前數字，不是你拿到手的錢。

## 六、申請流程

```
1. 確認職種與自身條件（學歷不要求，但年齡 18 歲以上）
2. 考過日語測驗（N4 或 JFT-Basic）
3. 考過該職種的技能評量測驗
4. 媒合雇主，簽訂雇用契約
5. 雇主／登錄支援機關擬定「支援計畫」
6. 申請在留資格認定證明書（COE），審查約 1～3 個月
7. 取得 COE 後在台辦理簽證
8. 入境、領在留卡、辦住民登錄與健保
9. 入職，並接受支援機關的定期生活支援
```

**第五步是特定技能特有的制度設計。** 雇主必須自行或委託「登錄支援機關」提供生活支援——包含事前說明、入境接送、住居確保、生活指導、日語學習機會、諮詢窗口、定期面談等。

**這是你在選雇主時該檢查的重點。** 支援計畫寫得完整、有實際運作的公司，和只是為了通過審查而交差的公司，到日本後的生活差距非常大。可以直接問：支援機關是哪一家？多久面談一次？生活上有問題找誰？

## 七、五年之後的三條路

一號的五年上限是硬性的。到期前要選一條：

| 路徑 | 條件 | 結果 |
|------|------|------|
| **轉特定技能二號** | 該職種有開放二號，且通過熟練技能考核 | 可長期居留、可帶家人、可累積永住年數 |
| **取得學歷轉技人國** | 在日本念專門學校或大學，職務相關 | 無在留上限、可帶家人 |
| **返台** | — | 經驗與日語成為台灣日商的優勢 |

**第三條路不是失敗。** 五年的日本現場經驗加上日語能力，在台灣的日商、日本客戶往來的製造業與貿易公司，是很有價值的資歷。重點是**要事先知道自己走哪條，並據此安排這五年**——想轉二號就要累積熟練度與考核資格，想轉技人國就要提早規劃入學與資金。

## 常見問題

**Q：真的完全不要求學歷嗎？**
A：是，特定技能不要求學歷，這是它和技人國最大的差別。要求的是年齡 18 歲以上、日語測驗合格、技能測驗合格。

**Q：可以帶配偶和小孩去日本嗎？**
A：**一號不可以。** 二號可以申請家族滯在讓配偶與未成年子女同住。這是決定路線時最該先想清楚的一點。

**Q：可以換公司嗎？**
A：同一職種內可以轉職，但須辦理在留資格相關的變更手續，不是自己換了就算。這點和技能實習明顯不同。

**Q：五年期間可以中斷嗎？**
A：通算五年是累計在留期間，中途返台再入境，已使用的期間仍會計入。

**Q：特定技能可以申請永住嗎？**
A：一號的在留期間原則上不計入永住所需年數。二號則可累積。**想走永住，二號是必經之路。**

**Q：技能測驗在台灣考得到嗎？**
A：依職種與年度而異，有些在台灣或東南亞舉辦，有些必須到日本考。報名前務必確認該職種當年度的實施地點與場次。
