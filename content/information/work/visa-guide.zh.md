日本建設業的人力短缺已經不是趨勢，是現實。越來越多企業把目光轉向海外人才，但「要用哪一種在留資格」這一步選錯，輕則申請被駁回，重則錄用後才發現職務內容與資格不符，面臨更新被拒的風險。

這篇從企業端的角度，完整說明建設業雇用外國施工管理職的制度選擇與實務流程。

---

## 一、兩種路線的根本差異

![日本建設工地現場，施工管理人員檢視工程進度](/images/information/visa-guide/apply.jpg)

| | 技術・人文知識・國際業務（技人國） | 特定技能（建設分野） |
|------|------|------|
| 定位 | **白領技術職** | **現場實務職** |
| 學歷要求 | 大學／專門學校畢業，**且與職務相關** | **不要求** |
| 日語要求 | 法規無明訂（實務多要 N2） | JLPT N4 或 JFT-Basic |
| 技能測驗 | 不需要 | **需通過建設分野技能測驗** |
| 可從事內容 | 施工管理、設計、技術指導、技術翻譯 | 現場作業為主 |
| **現場作業** | **原則不可** | 可 |
| 在留期限 | 可反覆更新，**無上限** | 一號**通算 5 年**；二號無上限 |
| 可帶家人 | **可** | 一號**不可**；二號可 |
| 通往永住 | 可 | 一號原則不計入；二號可 |
| 業界團體加入 | 不需要 | **須加入 JAC** |

※ 制度細節與開放範圍會調整，申請前請以出入國在留管理廳與國土交通省當年度公告為準。

## 二、施工管理職該選哪一個

**純粹的施工管理職務，原則上走「技人國」。**

因為施工管理的本質是工程進度、品質、安全、成本的管理與技術判斷，屬於技人國定義的技術業務。而特定技能（建設分野）的設計目的是補充**現場作業**人力。

### 但這裡有個企業最常踩的雷

**技人國的持有者不能從事現場作業。**

錄用時寫的是「施工管理」，實際卻讓人每天在工地做鋼筋綁紮、模板組立——這叫資格外活動。後果是：

- 在留期間更新時被拒
- 企業端可能被認定為不當雇用，影響往後的受入資格
- 當事人可能面臨在留資格取消

**判斷標準不是職稱，是實際工作內容。** 如果這個職位有相當比例的現場作業，就不該用技人國。

### 相關性的門檻

技人國要求學歷與職務相關。施工管理對應的是土木、建築、都市工學等科系。**文科背景要做施工管理，相關性很難說通**，除非能證明有足夠的相關實務經驗。

## 三、技人國的申請要點

| 條件 | 說明 |
|------|------|
| 學歷 | 大學、大學院，或日本的專門學校畢業，**科系與職務相關** |
| 職務內容 | 須屬技術或知識性業務，不可為單純現場作業 |
| **薪資** | **須與同職務的日本人同等以上**（法定要求） |
| 雇用形態 | 正式雇用契約，非派遣的短期臨時 |
| 企業穩定性 | 審查會看公司的事業規模、財務狀況與雇用實績 |

**薪資條款是法定要求，不是建議。** 明顯低於同職位日本人的待遇，申請不會通過——這個條款同時也是對企業的保護，避免日後的勞資爭議。

## 四、特定技能（建設分野）的額外義務

![人事負責人整理外國人雇用的在留資格申請文件](/images/information/visa-guide/visa.jpg)

如果職務確實是現場實務型，走特定技能，企業要承擔比技人國多得多的義務：

| 義務 | 內容 |
|------|------|
| **加入 JAC** | 須加入建設技能人材機構（或透過所屬團體加入），並繳納負擔金 |
| **受入計畫認定** | 須取得國土交通大臣的建設特定技能受入計畫認定 |
| **報酬的安定性** | 須為月給制，不可用日給月給等不穩定形式 |
| **支援計畫** | 須自行或委託登錄支援機關提供生活支援 |
| 定期報告 | 須依規定提出受入狀況報告 |

**JAC 加入與受入計畫認定是建設分野特有的**，其他產業的特定技能沒有這兩項。很多企業在評估時只看到技能測驗，漏算了這部分的行政成本與時程。

### 支援計畫包含什麼

事前說明、入境接送、住居確保、生活指導（開戶、手機、垃圾分類等）、日語學習機會、諮詢窗口、定期面談、公私手續的協助。

**這不是形式。** 做得紮實的企業，人才定著率明顯較高；只為通過審查而交差的，往往在第一年就流失。

## 五、申請流程與時程

```
1. 確認職務內容 → 決定在留資格路線
2. 人選甄選、確認學歷／技能測驗資格
3. 簽訂雇用契約（薪資、職務內容須明確）
4. （特定技能）加入 JAC、取得受入計畫認定
5. （特定技能）擬定支援計畫
6. 向出入國在留管理局申請 COE
7. COE 審查：約 1～3 個月
8. 人選持 COE 在母國辦簽證（約 1～2 週）
9. 入境、住民登錄、加入社會保險
10. 入職；（特定技能）持續執行支援與定期報告
```

**從決定錄用到實際到職，現實上要抓 3～6 個月。** 特定技能因為多了 JAC 與受入計畫認定，通常比技人國再多 1～2 個月。急件趕工的專案不適合用這條路補人。

### 主要文件

| 類別 | 文件 |
|------|------|
| 企業端 | 登記事項證明書、決算書、事業內容說明、雇用理由書 |
| 契約 | 雇用契約書、職務內容說明書、薪資明細 |
| 人選端 | 護照、學歷證明（翻譯）、職務經歷書、技能測驗合格證（特定技能） |
| 特定技能額外 | JAC 加入證明、受入計畫認定證、支援計畫書 |

## 六、常見的駁回原因

| 原因 | 說明 |
|------|------|
| **職務內容與在留資格不符** | 技人國申請書寫施工管理，實際是現場作業 |
| 學歷與職務相關性不足 | 非相關科系又無足夠實務經驗 |
| 薪資低於日本人同等水準 | 法定要件不符 |
| 企業事業規模或財務狀況存疑 | 審查會評估企業是否有持續雇用能力 |
| 職務內容說明過於籠統 | 寫不清楚每天實際做什麼 |
| 過去的受入違規紀錄 | 影響往後申請 |

**最常見的第一項，根源通常不是刻意規避，而是企業在填申請書時把職務寫得比實際「漂亮」。** 寫得過於白領、實際做現場，更新時就會出問題。誠實依實際內容選擇資格，才是長期可持續的作法。

---

## 七、企業端的實務建議

1. **先定義職務，再選資格。** 把這個職位每天實際做什麼寫下來，現場作業佔多少比例，再決定路線。
2. **把時程算進專案計畫。** 3～6 個月是常態，不要當成可以隨時補的人力。
3. **薪資比照日本人，不要試圖壓低。** 這是法定要件，也是定著率的基礎。
4. **支援做確實。** 特定技能的支援計畫是義務，但做得好壞直接反映在留任率上。
5. **留下完整紀錄。** 職務內容、出勤、薪資、支援執行狀況，更新與定期報告時都會用到。

## 常見問題

**Q：可以先用特定技能進來，之後轉技人國嗎？**
A：資格變更在制度上可能，但須符合技人國的學歷與職務相關性要件。如果人選沒有相關學歷，實務上難度很高。建議一開始就依人選條件選對路線。

**Q：特定技能一號五年到期後怎麼辦？**
A：建設分野有特定技能二號，符合熟練技能要件者可轉二號，在留無上限、可帶家人、可累積永住年數。**這件事應該在錄用第一年就開始規劃**，而不是第五年才處理。

**Q：技能實習生可以直接轉特定技能嗎？**
A：完成技能實習二號者，通常可免除技能與日語測驗轉特定技能一號（須同一或相關職種）。這是建設業最常見的銜接路徑。

**Q：日語能力真的需要到 N2 嗎？**
A：技人國法規沒有明訂日語門檻，但施工管理需要與協力廠商、現場作業員、發注者溝通，實務上 N2 是合理期待。安全指示的溝通落差在工地是直接的風險。

**Q：沒有大學學歷但有十年現場經驗，可以做施工管理嗎？**
A：技人國在「國際業務」類別有實務經驗的替代路徑，但技術類別對學歷要求較嚴。個案差異大，建議先做資格評估。
