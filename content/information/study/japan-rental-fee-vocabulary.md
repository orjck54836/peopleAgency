打開日本租屋網站，費用欄位往往是這樣寫的：

**「家賃 65,000円 / 管理費 5,000円 / 敷金 2ヶ月 / 礼金 1ヶ月 / 仲介手数料 1ヶ月」**

每個詞都像是認識，但真正要算清楚「入住這間房子要準備多少錢」，很多人還是算不出來。

這篇文章把日本租屋所有費用項目的日文用語逐一解析，讓你在看廣告、談合約時不再霧煞煞。

---

## 一、每月固定費用

這是每個月必須支付的費用，租屋期間每月都會扣。

### 家賃（やちん）＝ 月租金

```
家賃：65,000円
```

這是最核心的費用，就是每個月的房租。日本租屋廣告上標示的「家賃」就是純月租金，不含其他費用。

**讀音：** やちん（ya-chin）

---

### 管理費（かんりひ）＝ 管理費

```
管理費：5,000円
```

每月另外收取的大樓管理費用，用於維護公共區域（走廊、電梯、停車場、垃圾場等）的清潔與修繕。

**注意：** 管理費不包含在家賃裡，實際每月支出 = 家賃 ＋ 管理費。上面的例子每月實際要付 **70,000 日圓**，不是 65,000 日圓。

**讀音：** かんりひ（kan-ri-hi）

---

### 共益費（きょうえきひ）＝ 共益費

```
共益費：3,000円
```

與管理費性質相同，部分物件用「共益費」這個名稱。有些物件兩者都收，有些只收其中一種，看廣告時要注意是否兩者並列。

**讀音：** きょうえきひ（kyō-e-ki-hi）

---

## 二、入住初期一次性費用

這些費用只在入住時收取一次，金額通常是月租的好幾倍，是最容易讓人措手不及的部分。

### 敷金（しききん）＝ 押金

```
敷金：2ヶ月
```

「敷金 2ヶ月」代表押金為 2 個月的月租金。這筆錢由房東保管，退租時扣除損壞修繕費用後退還給你。

**退還條件：**
- 自然耗損（壁紙老化、地板輕微磨損）→ 房東負擔，應退還
- 人為損壞（牆壁破洞、燒焦痕跡）→ 從押金扣除
- 清潔費 → 部分房東會扣除，建議退租前確認

**讀音：** しききん（shi-ki-kin）

---

### 礼金（れいきん）＝ 謝禮金

```
礼金：1ヶ月
```

「謝禮金」是日本特有的文化，表示感謝房東出租房屋的費用。這筆錢**無論如何都不會退還**，即使住了一個月就退租也一樣。

近年來越來越多物件標示「**礼金0ヶ月**」或「**礼金なし**」，代表不收謝禮金，對留學生來說是非常有利的條件，找房時優先選擇這類物件。

**讀音：** れいきん（re-i-kin）

---

### 仲介手数料（ちゅうかいてすうりょう）＝ 仲介費

```
仲介手数料：1ヶ月
```

透過不動產仲介租屋所支付的服務費，通常為一個月租金。部分物件標示「**仲介手数料無料**」代表免仲介費，通常是房東直接出租或開發商建案。

**讀音：** ちゅうかいてすうりょう（chū-kai-te-sū-ryō）

---

### 前払い家賃（まえばらいやちん）＝ 預付租金

```
前払い家賃：1～2ヶ月
```

入住時需要預付的租金，通常為 1～2 個月。如果在月中入住，有些房東會按比例收取當月剩餘天數的租金（日割り計算）。

**讀音：** まえばらいやちん（mae-ba-ra-i ya-chin）

---

### 保証会社費用（ほしょうがいしゃひよう）＝ 保證公司費用

```
保証会社：月額賃料等の50～100%
```

沒有日本個人保證人時，需要使用保證公司代為擔保。費用通常為月租的 50～100%，之後每年需繳納約 1 萬日圓的更新費。

對台灣留學生來說，這幾乎是必要支出，因為大多數人在日本沒有可以擔任保證人的親友。

**皓學提供的租屋管道已事先確認接受外國留學生申請，並協助處理保證公司的相關手續。**

**讀音：** ほしょうがいしゃひよう（ho-shō-gai-sha hi-yō）

---

### 火災保険料（かさいほけんりょう）＝ 火險費用

```
火災保険：15,000～20,000円（2年間）
```

日本租屋幾乎都強制要求加入火險，通常為 2 年一期，費用約 15,000～20,000 日圓。部分仲介會指定保險公司，但你有權利選擇其他家，費用通常可以更便宜。

**讀音：** かさいほけんりょう（ka-sai-ho-ken-ryō）

## 三、費用總整理：實際要準備多少錢？

以東京月租 65,000 日圓、管理費 5,000 日圓的 1K 物件為例：

| 費用項目 | 計算方式 | 金額 |
|---------|---------|------|
| 家賃（第一個月） | 65,000 日圓 | 65,000 日圓 |
| 管理費（第一個月） | 5,000 日圓 | 5,000 日圓 |
| 敷金 | 家賃 × 2 | 130,000 日圓 |
| 礼金 | 家賃 × 1 | 65,000 日圓 |
| 仲介手数料 | 家賃 × 1 | 65,000 日圓 |
| 保証会社費用 | 家賃 × 50% | 32,500 日圓 |
| 火災保険 | 2 年分 | 18,000 日圓 |
| **合計** | | **約 380,500 日圓** |

**一間月租 65,000 日圓的房子，入住時要準備將近 40 萬日圓（約台幣 8 萬元）。**

這就是為什麼赴日前一定要預留足夠的現金，光是租屋初期費用就會吃掉很大一筆預算。

## 四、退租相關費用日文

租屋不只有入住時有費用，退租時同樣有需要了解的用語：

| 日文 | 讀音 | 意思 |
|------|------|------|
| 退去 | たいきょ | 搬出、退租 |
| 解約 | かいやく | 解約、終止合約 |
| 解約予告 | かいやくよこく | 解約通知（通常需提前 1～2 個月通知） |
| 原状回復 | げんじょうかいふく | 原狀回復義務 |
| 修繕費 | しゅうぜんひ | 修繕費用 |
| 清掃費 | せいそうひ | 清潔費用 |
| 敷金精算 | しききんせいさん | 押金結算 |

**原状回復（げんじょうかいふく）** 是退租時最常產生爭議的地方。日本法律規定，自然耗損屬於房東責任，人為損壞才由房客負擔。退租前建議：
- 入住時拍照記錄房間狀況
- 退租時對照照片確認損壞來源
- 如果對押金扣除有爭議，可向消費者保護機構申訴

## 五、合約相關用語

| 日文 | 讀音 | 意思 |
|------|------|------|
| 賃貸借契約 | ちんたいしゃくけいやく | 租屋合約 |
| 契約期間 | けいやくきかん | 合約期間（通常 2 年） |
| 更新 | こうしん | 續約 |
| 更新料 | こうしんりょう | 續約金（通常為 1 個月租金） |
| 自動更新 | じどうこうしん | 自動續約 |
| 普通借家契約 | ふつうしゃっかけいやく | 一般租約（可無限續約） |
| 定期借家契約 | ていきしゃっかけいやく | 定期租約（到期不一定能續約，留學生要注意） |

> **留學生注意：** 申請定期借家契約（定期租約）前，務必確認合約到期時間是否與你的留學時間相符，否則到期後可能被要求搬出。

## 看廣告實戰：費用欄怎麼讀？

```
家賃：62,000円
管理費：3,000円
敷金：1ヶ月 / 礼金：0ヶ月
仲介手数料：無料
保証会社：利用必須
火災保険：加入必須
```

**解讀：**
- 每月支出：62,000 + 3,000 = **65,000 日圓**
- 押金：62,000 日圓（1 個月），退租時可退還
- 無謝禮金、無仲介費：**省下兩個月的費用**
- 需要使用保證公司：約 31,000 日圓（50%）
- 需要加入火險：約 18,000 日圓

**預估入住初期費用：約 176,000 日圓（含第一個月房租）**

這種標示「礼金0・仲介手数料無料」的物件，對留學生來說是非常划算的選擇，找房時優先搜尋這類條件。
