在日本留學期間，打工不只是賺生活費的方式——更是練習日文、融入日本社會最直接的機會。

但很多留學生到了日本才發現，課本上學的日文和工作現場用的完全不一樣。

這篇文章把打工從「找工作」到「領薪水」整個流程會用到的日文單字和句子，一次整理清楚。

## 二、求職網站常見標示

在日本求職網站（如 Indeed、タウンワーク、バイトル）找工作時，會看到這些關鍵字：

| 標示 | 意思 |
|------|------|
| 未経験歓迎 | 歡迎無經驗 |
| 外国人活躍中 | 外國人活躍中（歡迎外國人應徵） |
| 日本語N4以上 | 需要日檢 N4 以上 |
| 週1日〜OK | 最少每週 1 天即可 |
| 短期OK | 可短期工作 |
| 扶養内勤務 | 在扶養範圍內工作 |
| 即日勤務OK | 可立即上班 |

> 找工作時搜尋「**外国人歓迎**」或「**留学生歓迎**」，可以找到對外國人比較友善的職缺。

## 三、面試常用句

### 自我介紹

```
はじめまして。台湾から来た留学生の〇〇と申します。
（hajimemashite. taiwan kara kita ryūgakusei no 〇〇 to mōshimasu）
您好，我是來自台灣的留學生，我叫〇〇。
```

```
現在、〇〇語学学校に通っています。
（ima, 〇〇 gogaku gakkō ni kayotte imasu）
我目前就讀於〇〇語言學校。
```

### 工作意願

```
週に〇日、働くことができます。
（shū ni 〇nichi, hataraku koto ga dekimasu）
我每週可以工作〇天。
```

```
土日は必ず出勤できます。
（doyō nichiyō wa kanarazu shukkin dekimasu）
週六日我一定可以上班。
```

```
接客の仕事に興味があります。
（sekkyaku no shigoto ni kyōmi ga arimasu）
我對接待客人的工作很有興趣。
```

### 詢問條件

```
時給はいくらですか？
（jikyū wa ikura desu ka）
時薪是多少？
```

```
交通費は支給されますか？
（kōtsūhi wa shikyū saremasu ka）
有交通費補助嗎？
```

```
シフトの希望を出すことはできますか？
（shifuto no kibō wo dasu koto wa dekimasu ka）
可以提出希望的班表嗎？
```

## 六、留學生打工注意事項

### 每週上限 28 小時

持有學生簽證的留學生，依日本法規每週打工時數上限為 **28 小時**（長期放假期間每天 8 小時，每週最多 40 小時）。

超時打工不只違法，一旦被發現可能影響簽證續簽甚至被要求離境，務必遵守。

### 需要申請「資格外活動許可」

合法打工的前提是持有「**資格外活動許可**（しかくがいかつどうきょか）」，可以在入境日本時於機場申請，或事後向入管局提出申請。

沒有這個許可就打工屬於違法行為，請務必先辦理。
