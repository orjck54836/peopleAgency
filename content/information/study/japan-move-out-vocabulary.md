留學結束，要離開日本了。

機票訂好了、行李也開始整理——但你知道退租這件事，要在離開前幾個月就開始準備嗎？

很多留學生在退租時才發現：押金被扣了一大筆、清潔費算法看不懂、解約通知早了一天算多一個月房租。這些坑，都是因為不熟悉日本退租的規則和日文用語。

這篇文章把退租流程從頭到尾涉及的日文用語整理清楚，讓你離開日本前不留遺憾、不留糾紛。

## 一、退租通知相關用語

日本租屋最重要的規定之一：**退租前必須提前通知房東**。這個期限通常寫在你的合約裡，大多數是 1～2 個月前。

| 日文 | 讀音 | 意思 |
|------|------|------|
| 解約予告 | かいやくよこく | 解約預告（提前通知退租） |
| 解約予告期間 | かいやくよこくきかん | 解約預告期限（通常1～2個月） |
| 退去通知 | たいきょつうち | 退租通知 |
| 退去予定日 | たいきょよていび | 預計搬出日期 |
| 解約申込書 | かいやくもうしこみしょ | 解約申請書 |

**最容易踩的坑：**

如果你的合約寫「解約予告期間：2ヶ月」，代表你必須在搬出日的 **2 個月前**提出書面通知。如果你在 6 月 30 日搬出，你必須在 4 月 30 日之前通知房東。晚了一天，可能就要多付一個月租金。

退租通知通常需要以書面方式提出，可以用以下句子聯繫房東或仲介：

```
退去の意思をお伝えしたく、ご連絡いたしました。
退去予定日は〇〇年〇月〇日を予定しております。
解約申込書をお送りいただけますでしょうか。

（我想通知您退租事宜。
預計搬出日期為〇〇年〇月〇日。
請問可以寄送解約申請書給我嗎？）
```

## 二、搬出當天相關用語

| 日文 | 讀音 | 意思 |
|------|------|------|
| 退去 | たいきょ | 搬出、退租 |
| 退去立会い | たいきょたちあい | 退租驗屋（房東或仲介到場確認房況） |
| 鍵の返却 | かぎのへんきゃく | 交還鑰匙 |
| 室内確認 | しつないかくにん | 室內確認（驗屋） |
| チェックリスト | — | 確認清單 |
| 損傷 | そんしょう | 損壞 |
| 傷 | きず | 刮痕、傷痕 |
| 汚れ | よごれ | 污漬 |
| カビ | — | 黴菌 |

**退去立会い（退租驗屋）是最關鍵的步驟。**

搬出當天，房東或仲介通常會到場確認房間狀況，這個過程叫做「退去立会い」。驗屋結果直接決定押金能退多少。

建議在搬出前自己先做一次確認：
- 入住時拍的照片找出來，對照現在的狀況
- 清潔乾淨（特別是廚房、浴室、廁所）
- 確認所有設備正常運作

如果對驗屋結果有異議，當場就要說，不要簽名後再抗議：

```
この傷は入居前からあったものです。
（這個刮痕是入住前就有的。）

入居時の写真をお見せできます。
（我可以出示入住時的照片。）

この汚れは通常の使用によるものだと思います。
（這個污漬我認為是正常使用造成的。）
```

## 三、押金結算相關用語

| 日文 | 讀音 | 意思 |
|------|------|------|
| 敷金精算 | しききんせいさん | 押金結算 |
| 敷金返還 | しききんへんかん | 押金退還 |
| 差引額 | さしひきがく | 扣除金額 |
| 修繕費 | しゅうぜんひ | 修繕費用 |
| 清掃費 | せいそうひ | 清潔費用 |
| ハウスクリーニング | — | 專業清潔費（通常由房客負擔） |
| 壁紙張替費 | かべがみはりかえひ | 壁紙更換費 |
| フローリング補修費 | — | 地板修復費 |

**敷金精算書（押金結算書）** 通常在搬出後 1～2 個月內寄到你的郵件信箱（或電子郵件）。這份文件列出所有扣除項目和最終退還金額。

收到後務必仔細確認每一個項目，如果有不合理的扣費，有權提出異議。

## 四、原状回復：最容易產生糾紛的地方

「**原状回復（げんじょうかいふく）**」是日本退租最常見的爭議來源。

原狀回復的義務是指：退租時需要將房間恢復到「入住時的狀態」。但這不代表所有損壞都由房客負擔。

### 日本法律的規定

日本國土交通省的「**原状回復をめぐるトラブルとガイドライン**」明確規定：

| 損壞類型 | 負擔方 |
|---------|--------|
| 自然耗損（Natural Wear） | 房東負擔 |
| 人為損壞（故意或過失） | 房客負擔 |

### 自然耗損（房東應負擔）的例子

| 日文 | 意思 |
|------|------|
| 経年劣化 | 因年歲老化造成的自然耗損 |
| 日焼けによる変色 | 陽光照射造成的褪色 |
| 壁紙の自然な黄ばみ | 壁紙自然泛黃 |
| 畳の自然な変色 | 榻榻米自然變色 |
| 画鋲・ピンの穴（小さなもの） | 圖釘小孔（一般用途） |

### 人為損壞（房客應負擔）的例子

| 日文 | 意思 |
|------|------|
| タバコのヤニ汚れ | 菸草焦油污漬 |
| ペットによる損傷 | 寵物造成的損壞 |
| 結露放置によるカビ | 未處理結露造成的黴菌 |
| 大きな釘穴 | 大型釘孔 |
| 故意または過失による傷 | 故意或過失造成的刮痕 |

**如果房東要求你負擔應屬自然耗損的費用，你可以這樣回應：**

```
このガイドラインによると、経年劣化による壁紙の変色は
貸主負担とされています。
（根據這份指南，因自然耗損造成的壁紙變色應由房東負擔。）

国土交通省のガイドラインを確認させてください。
（請讓我確認國土交通省的指南。）
```

## 五、退租後的手續

搬出日本後，還有幾件事需要處理：

| 項目 | 日文 | 說明 |
|------|------|------|
| 轉居通知 | 転出届（てんしゅつとどけ） | 向區役所辦理轉出，告知已離開 |
| 國民健保退出 | 国民健康保険喪失届 | 辦理健保退出手續 |
| 銀行帳戶 | 口座解約 | 若不再回日本，考慮關閉帳戶 |
| 手機合約 | 解約 | 辦理手機合約解除 |
| 郵件轉寄 | 転送届（てんそうとどけ） | 向郵局辦理郵件轉寄（可線上辦理） |

## 六、退租溝通常用句整理

**通知退租：**
```
お世話になっております。
〇月〇日をもちまして退去したい旨、ご連絡いたします。
（您好，謹此通知我預計於〇月〇日退租。）
```

**詢問押金退還時程：**
```
敷金の返還はいつ頃になりますでしょうか？
（請問押金大約何時會退還？）
```

**對扣費項目提出異議：**
```
この費用の詳細をご説明いただけますでしょうか？
（能否請您說明這筆費用的詳細內容？）

入居時の状態と変わらないと思うのですが、確認をお願いできますか？
（我認為這和入住時的狀況相同，能否請您再次確認？）
```

**確認押金結算書：**
```
敷金精算書を拝受いたしました。内容を確認いたします。
（已收到押金結算書，我將確認內容。）
```

## 退租前的準備清單

離開日本前，按照這個順序處理：

- **搬出前 2 個月**：確認合約的解約予告期限，提出書面通知
- **搬出前 1 個月**：開始整理物品，確認所有家具家電狀況
- **搬出前 1 週**：徹底清潔房間，特別是廚房、浴室
- **搬出當天**：退去立会い（驗屋），確認鑰匙交還，拍照存證
- **搬出後 1～2 個月**：收到敷金精算書，確認退還金額
