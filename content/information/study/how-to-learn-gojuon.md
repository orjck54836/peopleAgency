背五十音最快的方法是**一次只背一行、每天邊背邊唸、隔天先複習再往下**。每天 30 分鐘，平假名一週、片假名一週，兩週就能全部認得。不要一開始就把整張表從頭背到尾，那是最容易放棄的背法。

## 先搞懂五十音有哪些

| 種類 | 數量 | 例子 | 說明 |
|------|------|------|------|
| 清音 | 46 個 | あ、か、さ | 最基本的音，含「ん」 |
| 濁音 | 20 個 | が、ざ、だ、ば | 右上加兩點「゛」 |
| 半濁音 | 5 個 | ぱ、ぴ、ぷ、ぺ、ぽ | 右上加小圈「゜」 |
| 拗音 | 30 多個 | きゃ、しゅ、ちょ | 後面接小的「ゃ、ゅ、ょ」 |
| 促音 | — | きって | 小的「っ」，停一拍 |
| 長音 | — | おかあさん、コーヒー | 拉長一拍 |

平假名和片假名的音完全一樣，只是寫法不同。所以真正要「學」的音只有一套，片假名是第二套寫法。

## 14 天進度表

| 天數 | 內容 |
|------|------|
| 第 1 天 | あ行、か行 |
| 第 2 天 | さ行、た行（注意し、ち、つ的發音） |
| 第 3 天 | な行、は行（注意ふ） |
| 第 4 天 | ま行、や行、ら行、わ行、ん |
| 第 5 天 | 濁音、半濁音 |
| 第 6 天 | 拗音、促音、長音 |
| 第 7 天 | 平假名總複習：唸簡單的單字 |
| 第 8〜10 天 | 片假名清音，每天三到四行 |
| 第 11 天 | 片假名濁音、拗音、長音「ー」 |
| 第 12〜13 天 | 唸外來語：コーヒー、タクシー、コンビニ |
| 第 14 天 | 總複習：平假名、片假名混著唸 |

每天的順序固定就好：**先複習昨天的 → 學今天的新字 → 每個字唸出聲並寫三次 → 睡前再看一次**。

## 讓五十音記得住的四個方法

1. **一定要唸出聲**。只用眼睛看，認得了也唸不出來，之後聽力會很吃力。
2. **用聯想記字形**。例如「ぬ」像一碗麵、「め」沒有尾巴的圈；自己想的聯想最好記。
3. **背完一行就拿來拼字**。學完あ行和か行，就可以唸「あか」（紅）、「いえ」（家）。用得到的字比單獨的字母好記很多。
4. **用間隔複習**。今天背的，明天、三天後、一週後各看一次，比一天背十遍有效。

## 台灣人最容易搞混的字

| 容易搞混 | 分辨方法 |
|------|------|
| ぬ／め | ぬ 尾巴有一個圈，め 沒有 |
| ね／れ／わ | 看右邊的收尾：ね 打圈、れ 往外撇、わ 往內收 |
| さ／ち | 方向相反 |
| シ／ツ | シ 的兩點在左邊直著排、最後一筆由下往上挑；ツ 的兩點在上面橫著排、最後一筆由上往下撇 |
| ソ／ン | 同樣看最後一筆：ソ 由上往下撇、ン 由下往上挑 |
| る／ろ | る 尾巴有圈，ろ 沒有 |

片假名的「シツソン」是所有人都會卡的一關，寫的時候特別注意最後一筆的方向。
