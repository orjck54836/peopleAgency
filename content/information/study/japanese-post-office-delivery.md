在日本郵局寄東西，把東西放上窗口說「**台湾までお願いします**」（麻煩寄到台灣），店員就會接著問你要用哪一種方式寄。

下面分成四個場景：寄明信片和信、寄包裹回台灣、行李宅配、收件與再配達。

## 一、先看懂這些字

| 日文 | 讀音 | 意思 |
|------|------|------|
| 郵便局 | ゆうびんきょく | 郵局 |
| ポスト | ポスト | 郵筒 |
| 切手 | きって | 郵票 |
| はがき | はがき | 明信片 |
| 封筒 | ふうとう | 信封 |
| 航空便／船便 | こうくうびん／ふなびん | 航空／海運 |
| 小包 | こづつみ | 包裹 |
| 宅配便 | たくはいびん | 宅配 |
| 送り状／伝票 | おくりじょう／でんぴょう | 託運單 |
| 元払い／着払い | もとばらい／ちゃくばらい | 寄件人付費／收件人付費 |
| 追跡番号 | ついせきばんごう | 追蹤號碼 |
| 不在票 | ふざいひょう | 不在通知單 |
| 再配達 | さいはいたつ | 重新配送 |

郵局的窗口通常分成「郵便」（寄信、寄包裹）和「貯金・保険」（存款、保險）兩邊，寄東西要排「郵便」那一邊。大一點的郵局是抽號碼牌。

## 二、寄明信片和信

| 誰說 | 日文 | 讀音 | 意思 |
|------|------|------|------|
| 你 | 台湾までエアメールでお願いします | たいわんまでエアメールでおねがいします | 寄到台灣，麻煩用航空 |
| 你 | 台湾までのはがきの切手を五枚ください | たいわんまでのはがきのきってをごまいください | 請給我五張寄台灣明信片的郵票 |
| 你 | 台湾までいくらですか | たいわんまでいくらですか | 寄到台灣多少錢 |
| 你 | 何日くらいかかりますか | なんにちくらいかかりますか | 大概要幾天 |
| 店員 | 一週間ほどで届きます | いっしゅうかんほどでとどきます | 大約一週會到 |
| 你 | 記念切手はありますか | きねんきってはありますか | 有紀念郵票嗎 |
| 店員 | こちらでお預かりします | こちらでおあずかりします | 這邊幫您收下（直接交寄） |

郵筒通常有兩個投入口，一邊是一般的信和明信片，另一邊是「速達・国際郵便・大型郵便」，寄回台灣的要投國際郵件那一邊。只有一個口的小郵筒就直接投。

## 三、寄包裹回台灣

| 誰說 | 日文 | 讀音 | 意思 |
|------|------|------|------|
| 你 | これを台湾に送りたいんですが | これをたいわんにおくりたいんですが | 我想把這個寄到台灣 |
| 店員 | 航空便と船便、どちらにしますか | こうくうびんとふなびん、どちらにしますか | 要寄航空還是海運 |
| 你 | 一番安い方法でお願いします | いちばんやすいほうほうでおねがいします | 麻煩用最便宜的方式 |
| 你 | EMS でお願いします | イーエムエスでおねがいします | 麻煩用 EMS |
| 店員 | 中身は何ですか | なかみはなんですか | 裡面是什麼 |
| 你 | 服とお菓子です | ふくとおかしです | 衣服和零食 |
| 你 | これは送れますか | これはおくれますか | 這個可以寄嗎 |
| 店員 | ラベルはお作りになりましたか | ラベルはおつくりになりましたか | 寄件標籤做好了嗎 |
| 你 | 箱はありますか | はこはありますか | 有賣箱子嗎 |
| 你 | 補償はつけられますか | ほしょうはつけられますか | 可以加保嗎 |

速度由快到慢是 EMS、航空便、船便，價格也是照這個順序由高到低。船便便宜很多，但要等一到兩個月，適合寄不急的書和冬衣。

寄件標籤要在出發前用手機在「国際郵便マイページサービス」填好，內容物一項一項寫，到窗口出示 QR code 列印。現場才開始填會花很多時間。

## 四、行李宅配

| 誰說 | 日文 | 讀音 | 意思 |
|------|------|------|------|
| 你 | スーツケースを空港に送りたいんですが | スーツケースをくうこうにおくりたいんですが | 我想把行李箱寄到機場 |
| 你 | このホテルに送りたいんですが | このホテルにおくりたいんですが | 我想寄到這間飯店 |
| 店員 | お届け日はいつにしますか | おとどけびはいつにしますか | 要哪一天送達 |
| 你 | 明日の午前中に届きますか | あしたのごぜんちゅうにとどきますか | 明天上午會到嗎 |
| 店員 | 最短で明後日になります | さいたんであさってになります | 最快是後天 |
| 店員 | 時間指定はありますか | じかんしていはありますか | 要指定時段嗎 |
| 你 | 元払いでお願いします | もとばらいでおねがいします | 我這邊付運費 |
| 店員 | 割れ物は入っていますか | われものははいっていますか | 裡面有易碎品嗎 |
| 店員 | こちらが控えです | こちらがひかえです | 這是您的收執聯 |

便利商店也能寄宅配，直接把東西拿到櫃台說「宅配便をお願いします」。每家便利商店合作的業者不同，託運單也不一樣，跟店員拿就好。寄到飯店時，收件人要寫飯店名稱、入住日期和訂房的名字，並先跟飯店說一聲。

## 五、收件與再配達

| 誰說 | 日文 | 讀音 | 意思 |
|------|------|------|------|
| 配送員 | お届け物です | おとどけものです | 您的包裹到了 |
| 配送員 | サインをお願いします | サインをおねがいします | 麻煩簽名 |
| 你 | 再配達をお願いしたいんですが | さいはいたつをおねがいしたいんですが | 我想申請重新配送 |
| 對方 | 追跡番号をお願いします | ついせきばんごうをおねがいします | 請告訴我追蹤號碼 |
| 你 | 明日の夜、七時以降でお願いします | あしたのよる、しちじいこうでおねがいします | 麻煩明天晚上七點以後 |
| 你 | 営業所で受け取れますか | えいぎょうしょでうけとれますか | 可以到營業所領嗎 |
| 你 | 置き配でお願いします | おきはいでおねがいします | 麻煩放門口就好 |

再配達用不在票上的 QR code 在網路上申請最快，不用講電話。到郵局或營業所窗口領的話，要帶不在票和有照片的證件，例如在留卡或護照。

## 台灣人常卡住的地方

1. **國際包裹的單子要先在線上做**。現在寄物品到國外，手寫的標籤可能不被受理，到了窗口才發現就得當場用手機重填。
2. **行李宅配不是當天到**。寄到機場通常要提早一到兩天，而且要寫清楚航班和出發時間，在機場的宅配櫃台領。
3. **不在票不要丟**。上面的號碼是領包裹的依據。留學生剛搬進宿舍或租屋處，信用卡、在留相關的掛號信常常就是這樣錯過的。
4. **不能寄的東西比想像多**。行動電源、噴霧、指甲油、香水、打火機都屬於不能用航空寄的物品，裝箱前先分開。
