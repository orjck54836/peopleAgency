到日本泡溫泉，在櫃台說「**日帰り入浴、大人二人お願いします**」（日歸入浴，大人兩位）就能買票進場。接下來幾乎不太需要開口，重點反而是看懂標示、知道入浴的規矩。

下面照順序整理：櫃台、看懂標示、入浴規矩、溫泉旅館、身體不舒服時。

## 一、先看懂這些字

| 日文 | 讀音 | 意思 |
|------|------|------|
| 日帰り入浴 | ひがえりにゅうよく | 日歸入浴（只泡湯不住宿） |
| 入浴料 | にゅうよくりょう | 入浴費 |
| 男湯／女湯 | おとこゆ／おんなゆ | 男湯／女湯 |
| 脱衣所 | だついじょ | 更衣處 |
| 内湯 | うちゆ | 室內浴池 |
| 露天風呂 | ろてんぶろ | 露天浴池 |
| 貸切風呂／家族風呂 | かしきりぶろ／かぞくぶろ | 包場浴池／家庭浴池 |
| 源泉かけ流し | げんせんかけながし | 源泉放流（不循環使用） |
| 足湯 | あしゆ | 足湯 |
| 湯上がり処 | ゆあがりどころ | 泡完湯的休息區 |
| 貴重品ロッカー | きちょうひんロッカー | 貴重物品置物櫃 |

## 二、在櫃台

| 誰說 | 日文 | 讀音 | 意思 |
|------|------|------|------|
| 你 | 日帰り入浴はできますか | ひがえりにゅうよくはできますか | 可以只泡湯嗎 |
| 你 | 日帰り入浴、大人二人お願いします | ひがえりにゅうよく、おとなふたりおねがいします | 日歸入浴，大人兩位 |
| 店員 | お一人様八百円です | おひとりさまはっぴゃくえんです | 一位八百日圓 |
| 你 | タオルは借りられますか | タオルはかりられますか | 可以租毛巾嗎 |
| 你 | 何時まで入れますか | なんじまではいれますか | 可以泡到幾點 |
| 你 | シャンプーは置いてありますか | シャンプーはおいてありますか | 裡面有洗髮精嗎 |
| 你 | タトゥーがあるんですが、入れますか | タトゥーがあるんですが、はいれますか | 我有刺青，可以進去嗎 |
| 你 | 貸切風呂は予約できますか | かしきりぶろはよやくできますか | 包場浴池可以預約嗎 |

有些日歸溫泉是在入口的售票機買「入浴券」，再把票交給櫃台。鞋子通常在玄關就要脫掉，放進鞋櫃（下駄箱，げたばこ）。

## 三、浴場裡會看到的標示

| 日文 | 讀音 | 意思 |
|------|------|------|
| かけ湯をしてからお入りください | かけゆをしてからおはいりください | 請先沖過身體再入池 |
| タオルを湯船に入れないでください | タオルをゆぶねにいれないでください | 請不要把毛巾放進浴池 |
| 髪の長い方は結んでください | かみのながいかたはむすんでください | 長髮請綁起來 |
| 浴室内での撮影は禁止です | よくしつないでのさつえいはきんしです | 浴室內禁止拍照 |
| 飲酒後の入浴はご遠慮ください | いんしゅごのにゅうよくはごえんりょください | 飲酒後請勿入浴 |
| 刺青・タトゥーのある方はお断りします | いれずみ・タトゥーのあるかたはおことわりします | 謝絕有刺青者 |
| 水着の着用はできません | みずぎのちゃくようはできません | 不可穿泳衣 |
| 清掃中 | せいそうちゅう | 清掃中（暫停使用） |

日本的溫泉是不穿衣物入浴的。小毛巾可以帶進浴場，泡的時候放在頭上或池邊，不要浸到水裡。

## 四、入浴的順序

1. 在脫衣所把衣物放進籃子或置物櫃，只帶小毛巾進浴場。
2. 先在洗澡區坐著把身體洗乾淨，或至少舀水沖過（かけ湯）。
3. 進浴池慢慢泡。水溫通常比台灣的溫泉池高，不用勉強泡很久。
4. 離開浴場前先用小毛巾把身上的水擦一下，再走回脫衣所，免得地板濕滑。

洗澡區用過的椅子和水盆，沖一下放回原位是基本禮貌。

## 五、住溫泉旅館時

| 誰說 | 日文 | 讀音 | 意思 |
|------|------|------|------|
| 你 | 大浴場は何時から何時までですか | だいよくじょうはなんじからなんじまでですか | 大浴場從幾點開到幾點 |
| 你 | 夕食は何時からですか | ゆうしょくはなんじからですか | 晚餐幾點開始 |
| 旅館 | ご夕食は六時と七時半、どちらになさいますか | ごゆうしょくはろくじとしちじはん、どちらになさいますか | 晚餐請問要六點還是七點半 |
| 你 | 七時半でお願いします | しちじはんでおねがいします | 七點半 |
| 你 | 浴衣のサイズを変えてもらえますか | ゆかたのサイズをかえてもらえますか | 可以幫我換浴衣的尺寸嗎 |
| 你 | 浴衣で館内を歩いてもいいですか | ゆかたでかんないをあるいてもいいですか | 可以穿浴衣在館內走動嗎 |
| 你 | 朝も温泉に入れますか | あさもおんせんにはいれますか | 早上也可以泡湯嗎 |
| 旅館 | お布団はお食事の間に敷かせていただきます | おふとんはおしょくじのあいだにしかせていただきます | 棉被會在您用餐時幫您鋪好 |

浴衣的穿法是**左襟在上**（從自己看是右邊先包、左邊蓋上去），相反的穿法是往生者的穿法。溫泉旅館的住宿費之外，每人每晚還會另收一筆「入湯税」（にゅうとうぜい），多半是 150 日圓左右，退房時一起付。

## 六、身體不舒服的時候

| 日文 | 讀音 | 意思 |
|------|------|------|
| のぼせてしまいました | のぼせてしまいました | 我泡到頭暈了 |
| 気分が悪いです | きぶんがわるいです | 我不太舒服 |
| お水をいただけますか | おみずをいただけますか | 可以給我一杯水嗎 |
| 少し休めるところはありますか | すこしやすめるところはありますか | 有可以休息一下的地方嗎 |

「のぼせる」是泡太久頭暈、臉發熱的狀態。覺得不對就先離開浴池，坐著休息、喝水。

## 台灣人常卡住的地方

1. **不能穿泳衣、不能包浴巾下水**。除了少數標明「水着着用」的混浴或溫泉樂園，一般浴場都是裸身入浴。
2. **先洗再泡**。沒洗身體就直接進浴池，是最容易被旁人提醒的事。
3. **手機不要帶進浴場**。就算只是看時間，在浴室拿出手機也會讓人以為你在拍照。
4. **刺青規定每間不同**。先查官網或直接問，被拒絕的話改找「貸切風呂」或標明「タトゥーOK」的設施。
5. **男女湯可能會對調**。很多旅館早晚各換一次，讓客人兩邊都泡得到，隔天早上不要憑記憶走進去。
