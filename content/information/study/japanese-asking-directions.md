用日文問路，一句「**すみません、〇〇はどこですか**」（不好意思，〇〇在哪裡）就夠了。真正的難關是聽懂回答：對方會一口氣講出直走、轉彎、第幾個路口。

所以這篇把重點放在「聽懂」，先學對方會用的詞，再學怎麼問。

## 一、開口問路

| 日文 | 讀音 | 意思 |
|------|------|------|
| すみません、駅はどこですか | すみません、えきはどこですか | 不好意思，車站在哪裡 |
| この辺に、コンビニはありますか | このへんに、コンビニはありますか | 這附近有便利商店嗎 |
| 〇〇に行きたいんですが | 〇〇にいきたいんですが | 我想去〇〇 |
| ここから歩いてどのくらいかかりますか | ここからあるいてどのくらいかかりますか | 從這裡走路要多久 |
| 歩いて行けますか | あるいていけますか | 走路到得了嗎 |
| この地図だと、どこですか | このちずだと、どこですか | 在這張地圖上是哪裡 |

「〇〇に行きたいんですが」後面不用把話說完，對方就會接著告訴你怎麼走，這是日文裡很自然的問法。

## 二、聽懂方向

| 日文 | 讀音 | 意思 |
|------|------|------|
| まっすぐ | まっすぐ | 直走 |
| 右 | みぎ | 右邊 |
| 左 | ひだり | 左邊 |
| 曲がる | まがる | 轉彎 |
| 渡る | わたる | 過（馬路、橋） |
| 戻る | もどる | 往回走 |

## 三、聽懂位置

| 日文 | 讀音 | 意思 |
|------|------|------|
| 角 | かど | 轉角 |
| 交差点 | こうさてん | 十字路口 |
| 信号 | しんごう | 紅綠燈 |
| 一つ目／二つ目 | ひとつめ／ふたつめ | 第一個／第二個 |
| 突き当たり | つきあたり | 路的盡頭 |
| 手前 | てまえ | 在……之前（靠自己這一側） |
| 向かい | むかい | 對面 |
| 隣 | となり | 隔壁 |
| 右側／左側 | みぎがわ／ひだりがわ | 右手邊／左手邊 |
| 〜の中 | 〜のなか | 在……裡面 |

「手前」最容易聽錯。「信号の手前」是「還沒到紅綠燈的地方」，不是過了紅綠燈。

## 四、對方的回答長這樣

把上面的詞串起來，就是實際會聽到的句子：

| 日文 | 讀音 | 意思 |
|------|------|------|
| まっすぐ行ってください | まっすぐいってください | 請直走 |
| 二つ目の角を右に曲がってください | ふたつめのかどをみぎにまがってください | 請在第二個轉角右轉 |
| まっすぐ行って、二つ目の角を右です | まっすぐいって、ふたつめのかどをみぎです | 直走，第二個轉角右轉 |
| 信号を渡って、左側にあります | しんごうをわたって、ひだりがわにあります | 過了紅綠燈，在左手邊 |
| コンビニの向かいにありますよ | コンビニのむかいにありますよ | 就在便利商店對面喔 |
| 突き当たりを左です | つきあたりをひだりです | 走到底左轉 |
| 歩いて五分くらいです | あるいてごふんくらいです | 走路大約五分鐘 |
| ちょっと遠いですよ | ちょっととおいですよ | 有點遠喔 |

聽的時候抓三樣東西就好：**方向**（右或左）、**第幾個**（一つ目、二つ目）、**地標**（信号、コンビニ）。

## 五、沒聽懂的時候

| 日文 | 讀音 | 意思 |
|------|------|------|
| すみません、もう一度お願いします | すみません、もういちどおねがいします | 不好意思，請再說一次 |
| ゆっくりお願いします | ゆっくりおねがいします | 請說慢一點 |
| 目印になるものはありますか | めじるしになるものはありますか | 有什麼可以當地標的嗎 |
| 右ですね | みぎですね | 是右邊對吧（複述確認） |

複述一次對方講的關鍵字是很好用的技巧，聽錯了對方會馬上糾正你。

## 六、迷路了

| 日文 | 讀音 | 意思 |
|------|------|------|
| 道に迷いました | みちにまよいました | 我迷路了 |
| 道に迷っちゃいました | みちにまよっちゃいました | 我迷路了（口語） |
| ここはどこですか | ここはどこですか | 這裡是哪裡 |
| 助けてもらえませんか | たすけてもらえませんか | 可以幫幫我嗎 |
| ありがとうございました | ありがとうございました | 謝謝你（問完之後說） |

## 台灣人常卡住的地方

1. **日本人不太講東南西北**。回答多半是「第幾個轉角」加上地標，數路口比看方位重要。
2. **日本的地址不好找**。同一個「丁目」裡的門牌不一定照順序排，拿地址問路人，對方也常常要想一下，用店名或地標問會快很多。
3. **「すぐそこ」不一定真的很近**。意思是「就在那邊」，實際可能要走三五分鐘。
