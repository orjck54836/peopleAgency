## 一、費用相關用語

這是租屋廣告裡最重要的區塊，搞懂費用才能真正比較不同物件。

| 日文 | 讀音 | 意思 | 備註 |
|------|------|------|------|
| 家賃 | やちん | 月租金 | 最核心的費用項目 |
| 管理費 | かんりひ | 管理費 | 每月另外收取，約 3,000～15,000 日圓 |
| 共益費 | きょうえきひ | 共益費 | 與管理費性質相同，部分物件用此稱呼 |
| 敷金 | しききん | 押金 | 通常為 1～2 個月租金，退租時可退還（扣除損壞費用） |
| 礼金 | れいきん | 謝禮金 | 給房東的禮金，**不退還**，近年越來越多物件已免收 |
| 仲介手数料 | ちゅうかいてすうりょう | 仲介費 | 通常為 1 個月租金，部分物件標示「仲介手数料無料」即免收 |
| 初期費用 | しょきひよう | 入住初期費用 | 以上所有費用加總，通常為月租的 4～6 倍 |
| 前払い家賃 | まえばらいやちん | 預付租金 | 通常需預付 1～2 個月 |
| 保証会社費用 | ほしょうがいしゃひよう | 保證公司費用 | 無保證人時使用，約月租的 50～100% |
| 更新料 | こうしんりょう | 續約金 | 合約到期續租時收取，通常為 1 個月租金 |
| 退去費用 | たいきょひよう | 退租費用 | 退租時的清潔與修繕費用 |
| 原状回復 | げんじょうかいふく | 原狀回復 | 退租時需將房間恢復原狀的義務 |

> **留學生重點：** 初期費用是最容易讓人措手不及的地方。以東京月租 6 萬日圓的物件為例，初期費用可能高達 30 萬日圓以上。出發前務必預留足夠的現金。

## 二、房型格局用語

### LDK 系統解碼

日本用「數字 ＋ 英文字母」標示房間格局，英文字母各代表不同空間：

| 字母 | 代表空間 | 說明 |
|------|---------|------|
| L | Living（客廳） | 獨立的客廳空間 |
| D | Dining（飯廳） | 獨立的用餐空間 |
| K | Kitchen（廚房） | 廚房空間 |
| R | Room（房間） | 廚房與房間合一（無隔間） |

**常見格局對照：**

| 標示 | 意思 | 適合對象 |
|------|------|---------|
| 1R | 單房無隔間（廚房與房間同一空間） | 預算最有限、只需睡覺空間 |
| 1K | 單房＋獨立廚房 | 大多數留學生的選擇 |
| 1DK | 單房＋飯廳廚房 | 需要獨立用餐空間 |
| 1LDK | 單房＋客廳飯廳廚房 | 預算較充裕 |
| 2K | 兩房＋廚房 | 合租或需要書房 |
| 2LDK | 兩房＋客廳飯廳廚房 | 家庭或多人合租 |

## 看廣告實戰練習

以下是一則真實租屋廣告的典型格式，對照上面的用語試著解讀：

```
家賃 65,000円
管理費 5,000円
敷金 1ヶ月 / 礼金 0ヶ月
築8年 / 7階建て / 3階
1K / 26.5㎡ / 南向き
オートロック・宅配ボックス・エレベーター
バス・トイレ別 / IHコンロ / 室内洗濯機置き場
最寄り駅：〇〇駅 徒歩7分
外国人可 / 保証会社利用可
```

**解讀：**
- 月租 6.5 萬日圓 ＋ 管理費 5,000 日圓 = 每月實際支出 7 萬日圓
- 押金 1 個月（6.5 萬），免禮金
- 屋齡 8 年，7 層樓建築的 3 樓
- 1K 格局，26.5 平方公尺，朝南
- 有自動門鎖、包裹代收箱、電梯
- 浴室廁所分開（加分項目）、IH 爐、室內洗衣機空間
- 距車站步行 7 分鐘
- 外國人可入住、可使用保證公司（無需個人保證人）
