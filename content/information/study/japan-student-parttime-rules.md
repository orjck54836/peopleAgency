「去日本留學可以打工嗎？打工能賺回學費嗎？」

可以打工，但有條件；能補貼生活費，但很難「賺回學費」。

這篇把規則講清楚——包含很多人沒注意、但一旦違規就可能影響簽證更新的細節。

---

## 一、打工前必須先拿到「資格外活動許可」

持「留學」在留資格的人，本職是學生。要打工，必須額外申請**資格外活動許可**（資格外活動許可書）。

**沒有這張許可就去打工，屬於非法工作**，即使只做一天、即使是朋友介紹的小忙。後果不只是罰則，更直接的是影響之後的在留期間更新與簽證申請。

### 怎麼申請

| 項目 | 說明 |
|------|------|
| 申請地點 | 入出國在留管理局（機場入境時也可當場申請） |
| 最省事的時機 | **入境當天在機場一起申請**，可當場取得 |
| 事後申請 | 到居住地管轄的在留管理局，約需 2 週～1 個月 |
| 費用 | 免費 |
| 效力 | 隨在留期間一併有效，更新在留時要一起更新 |

**最推薦的作法：入境時在機場就申請。** 機場的在留審查櫃台可以受理，當場在在留卡背面蓋章或核發許可書，省下之後跑一趟在留管理局、等上幾週的時間。很多學生不知道這件事，到日本後才發現要再排隊。

## 二、28 小時怎麼算（比你想的嚴格）

### 基本規則

| 期間 | 上限 |
|------|------|
| 一般學期中 | **每週 28 小時以內** |
| 學校規定的長假期間（暑假、寒假、春假） | **每日 8 小時以內、每週 40 小時以內** |

### 四個容易踩雷的細節

**1. 是「每週」，不是「平均每週」**
不能這週做 40 小時、下週做 16 小時來平均。**每一個單週都不能超過 28 小時。**

**2. 一週的起算日依在留管理局的解釋，任取連續七天都不得超過**
也就是說，就算你按月曆週沒超過，但「星期四到下週星期三」這七天超過了，同樣是違規。排班時要留安全餘裕。

**3. 多份打工要合計**
在便利商店做 20 小時、在餐廳做 12 小時，合計 32 小時——違規。**上限是所有工作加總**，不是每份工作各算。這是最常見的違規型態，因為兩家店各自看來都沒問題。

**4. 長假的放寬以「學校的行事曆」為準**
是學校正式公告的假期，不是你自己沒課的日子。學校沒放假，就算你那週沒排課，上限仍是 28 小時。

## 三、不能做的工作

以下屬於法律明文禁止留學生從事的範圍（風俗營業及相關行業），**即使有資格外活動許可也不行**：

- 柏青哥店（パチンコ）、麻將店、遊戲機店
- 酒吧、夜店、俱樂部的接待工作（キャバクラ、ホストクラブ 等）
- 情色相關行業
- 上述場所的清掃、洗碗等工作也包含在內

最後一項特別值得注意：**「我只是在柏青哥店打掃，沒有接待客人」並不能免責**。只要工作地點屬於風俗營業場所，就在禁止範圍內。這是留學生被取消在留資格的常見原因之一。

## 四、時薪行情與月收試算

時薪依都道府縣的最低工資與行業差異很大。以常見的留學生打工（便利商店、餐飲、飯店清掃、物流分裝）為大致範圍：

| 地區 | 常見時薪範圍 |
|------|------|
| 東京都 | 約 1,150～1,400 日圓 |
| 大阪府 | 約 1,100～1,300 日圓 |
| 愛知／神奈川／京都 | 約 1,050～1,250 日圓 |
| 福岡 | 約 980～1,150 日圓 |
| 其他地方城市 | 約 950～1,100 日圓 |

※ 日本最低工資每年十月調整，上表為概略區間，實際請以當地公告與職缺條件為準。深夜（22 時～翌 5 時）時段法定加給 25%。

### 月收試算（每週 28 小時、時薪 1,200 日圓）

```
1,200 日圓 × 28 小時 × 4.3 週 ≈ 144,000 日圓／月
```

扣掉交通費與不穩定的排班，實際多落在 **10～13 萬日圓**。長假期間拉到 40 小時，單月有機會到 20 萬日圓左右。

### 這筆錢夠做什麼？

| 項目 | 月額概算 |
|------|------|
| 房租（地方城市 1K） | 4～6 萬日圓 |
| 水電瓦斯網路 | 1～1.5 萬日圓 |
| 食費 | 3～4 萬日圓 |
| 交通・手機・雜支 | 1.5～2 萬日圓 |
| **合計** | **約 10～13 萬日圓** |

**結論很清楚：打工大致能覆蓋生活費，但覆蓋不了學費。** 語言學校一年學費約 70～90 萬日圓，必須另外準備。把「去日本打工賺學費」當作財務計畫，是最容易出事的規劃方式——因為它同時假設了你一定找得到工作、一定排得到班、而且不會生病。

## 五、稅與保險：兩個會被忽略的數字

**所得稅**：年收入超過一定額度會被扣稅，打工收入通常由店家源泉徵收。年收在扣除額以內者可透過確定申告退稅。

**國民健康保險**：持 6 個月以上留學簽證者依法須加入，醫療費自付約 30%。留學生因前一年在日本無申報所得，保費通常大幅減免，實際每月常在 1,000～2,000 日圓左右。**不要因為想省這筆錢而不加入**——一次急診或住院的自費金額，遠高於一整年的保費。

**國民年金**：原則上 20 歲以上須加入，但學生可申請「學生納付特例」緩繳。記得去區役所辦，不然會收到催繳單。

## 六、違規的後果

| 違規情形 | 可能後果 |
|------|------|
| 無許可打工 | 非法工作，影響在留更新，情節重大者可能遭退去強制 |
| 超過 28 小時 | 在留期間更新被拒、縮短在留期間 |
| 從事禁止行業 | 在留資格取消風險高 |

實務上最常被抓到的時機是**在留期間更新**或**簽證種類變更**時——在留管理局會調閱課稅證明與就業紀錄，時數異常一目了然。很多人想「做一下應該沒人知道」，但紀錄是後來才被對照出來的，而那時你正好最需要簽證順利更新。

另外，出席率不足也會連帶影響。語言學校通常要求出席率維持在 80～90% 以上，**打工到影響上課，才是真正讓你留不下來的原因**。

## 常見問題

**Q：剛到日本就能馬上開始打工嗎？**
A：有資格外活動許可就可以。但實務上多數學生會先花 1～2 個月安頓、適應課程、把日語練到能應對面試，再開始找工作。

**Q：日語多好才找得到打工？**
A：便利商店與餐飲的接客工作通常期待 N3 左右的對話能力；廚房內場、清掃、物流分裝對日語要求較低，是很多人的第一份工作。N5 程度要找到接客工作相當困難。

**Q：短期遊學（免簽）可以打工嗎？**
A：**完全不行。** 觀光免簽入境不具工作資格，也無法申請資格外活動許可。

**Q：寒暑假一週真的可以做 40 小時嗎？**
A：可以，但以學校正式公告的假期為限，且每日不超過 8 小時。假期結束當週就要回到 28 小時以內。

**Q：換工作要重新申請許可嗎？**
A：資格外活動許可是給「人」的，不綁定雇主，換工作不必重新申請。但要繼續遵守時數與行業限制。
