搬進日本的房子後，第一個讓人緊張的通常不是日文，是**垃圾**。

日本的垃圾分類由各市區町村自己訂，所以沒有一張全國通用的表。但大方向都差不多：可燃、不可燃、資源、大型四大類，**在指定的日子、指定的時間、用指定的袋子**拿到指定的地點。

這篇先整理垃圾相關的日文，再說明收集日曆怎麼看、常見東西怎麼分，最後是跟房東或鄰居溝通時用得到的句子。

---

## 一、先看懂這些字

| 日文 | 讀音 | 意思 |
|------|------|------|
| ごみ／ゴミ | ごみ | 垃圾 |
| 分別 | ぶんべつ | 分類 |
| 燃えるごみ／可燃ごみ | もえるごみ／かねんごみ | 可燃垃圾 |
| 燃えないごみ／不燃ごみ | もえないごみ／ふねんごみ | 不可燃垃圾 |
| 資源ごみ | しげんごみ | 資源垃圾（回收） |
| 粗大ごみ | そだいごみ | 大型垃圾 |
| 缶・びん・ペットボトル | かん・びん・ペットボトル | 鐵鋁罐・玻璃瓶・寶特瓶 |
| プラ（容器包装プラスチック） | プラ（ようきほうそうプラスチック） | 塑膠包裝容器 |
| 古紙 | こし | 舊紙類（報紙、紙箱） |
| 収集日 | しゅうしゅうび | 收集日 |
| ごみ集積所／ごみステーション | ごみしゅうせきじょ | 垃圾集中處 |
| 指定ごみ袋 | していごみぶくろ | 指定垃圾袋 |
| 収集カレンダー | しゅうしゅうカレンダー | 垃圾收集日曆 |

**「燃えるごみ」和「可燃ごみ」是同一個東西**，只是各地用詞不同。同樣地，有的地方叫「プラ」，有的叫「プラスチック製容器包装」，看到「プラ」兩個字就知道是塑膠類。

## 二、四大類大致怎麼分

| 分類 | 常見的東西 | 注意 |
|------|------|------|
| 可燃垃圾 | 廚餘、衛生紙、紙屑、髒掉的紙容器、衣物（部分地區） | 廚餘先**瀝乾水分**再丟 |
| 不可燃垃圾 | 陶瓷碗盤、玻璃碎片、小家電、雨傘、金屬製品 | 破掉的玻璃用紙包好，寫上「キケン」（危險） |
| 資源垃圾 | 寶特瓶、鐵鋁罐、玻璃瓶、紙箱、報紙、塑膠包裝 | 要**洗乾淨**，寶特瓶撕掉標籤、拿掉瓶蓋 |
| 大型垃圾 | 床墊、桌椅、腳踏車、棉被、行李箱 | 要**事先預約**，貼處理券 |

**同一樣東西，不同地區可能分在不同類。** 最常見的是塑膠：有的城市把塑膠當可燃垃圾燒，有的要分成「プラ」另外收。衣服、棉被、小家電也常因地區而異。不確定時，查自己城市的「ごみ分別辞典」（垃圾分類辭典），輸入品名就會告訴你是哪一類。

---

## 三、寶特瓶、紙箱、電池：最容易丟錯的東西

| 東西 | 怎麼處理 |
|------|------|
| 寶特瓶（ペットボトル） | 瓶蓋和標籤是**塑膠類**，瓶身洗過、壓扁，丟資源垃圾。很多超市和便利商店門口也有回收箱 |
| 紙箱（段ボール） | 攤平、用繩子綁成一捆，丟古紙日。有些地區不能裝進塑膠袋 |
| 牛奶紙盒（紙パック） | 洗過、剪開攤平，很多地區另外回收，超市也有回收箱 |
| 電池（乾電池） | 有的地區丟不可燃垃圾，有的要放到電器行或區役所的回收箱 |
| 鋰電池、行動電源 | **不能丟一般垃圾**，容易在垃圾車裡起火。拿到電器行的回收箱 |
| 噴霧罐、瓦斯罐（スプレー缶） | 用完，依地區規定戳洞或不戳洞，單獨放在透明袋裡 |
| 食用油 | 用凝固劑或紙吸乾後丟可燃垃圾，不能倒進水槽 |

## 四、收集日曆怎麼看

搬家時房東或管理公司通常會給一張「**ごみ収集カレンダー**」，或是告訴你區域的收集日。上面的寫法大概是這樣：

| 日曆上的寫法 | 意思 |
|------|------|
| 月・木　燃えるごみ | 每週一、四收可燃垃圾 |
| 第2・第4水曜　燃えないごみ | 每月第二、第四個星期三收不可燃垃圾 |
| 毎週金曜　資源ごみ | 每週五收資源垃圾 |
| 朝8時30分までに出してください | 請在早上 8:30 前拿出來 |
| 年末年始は収集を休みます | 年底年初停止收集 |

**不可燃垃圾通常一個月只收一兩次**，錯過要等很久，可以把日期設在手機行事曆裡。年底到年初（大約 12 月 31 日到 1 月 3 日）大多停收，過年前垃圾會特別多，提早整理。

## 五、跟房東、鄰居溝通的句子

| 情境 | 日文 | 讀音 | 意思 |
|------|------|------|------|
| 問收集日 | ごみの収集日を教えていただけますか | ごみのしゅうしゅうびをおしえていただけますか | 可以告訴我垃圾的收集日嗎 |
| 問地點 | ごみ置き場はどこですか | ごみおきばはどこですか | 垃圾放置處在哪裡 |
| 問袋子 | 指定のごみ袋はどこで買えますか | していのごみぶくろはどこでかえますか | 指定垃圾袋在哪裡買得到 |
| 問分類 | これは何ごみになりますか | これはなにごみになりますか | 這個是什麼垃圾 |
| 問時間 | 何時までに出せばいいですか | なんじまでにだせばいいですか | 要幾點前拿出去 |
| 被提醒後道歉 | すみません、分別を間違えてしまいました | すみません、ぶんべつをまちがえてしまいました | 對不起，我分錯了 |
| 被提醒後道歉 | 次から気をつけます | つぎからきをつけます | 下次會注意 |
| 不清楚規則 | まだルールがよくわからなくて… | まだルールがよくわからなくて | 我還不太清楚規則… |

被鄰居或管理員提醒時，**先道歉，再說會注意**，大部分的人就不會再追究。如果真的看不懂規則，直接說「まだルールがよくわからなくて」，很多鄰居反而會熱心教你。

## 六、大型垃圾怎麼丟

大型垃圾（粗大ごみ）不能直接放到垃圾集中處，流程是：

1. **預約**：打電話或上網到「粗大ごみ受付センター」，說要丟的東西和尺寸
2. **買處理券**：在便利商店或超市買「粗大ごみ処理券」，金額依品項從幾百到兩三千日圓不等
3. **貼上處理券**：寫上姓名或受理編號，貼在東西上
4. **在指定日期拿出去**：放在被告知的地點，通常是收集日當天早上

預約時會用到的句子：

| 日文 | 讀音 | 意思 |
|------|------|------|
| 粗大ごみの収集をお願いしたいんですが | そだいごみのしゅうしゅうをおねがいしたいんですが | 我想申請大型垃圾的收集 |
| ベッドのマットレスを一つ出したいです | ベッドのマットレスをひとつだしたいです | 我想丟一個床墊 |
| 処理券はいくらですか | しょりけんはいくらですか | 處理券要多少錢 |
| 一番早い収集日はいつですか | いちばんはやいしゅうしゅうびはいつですか | 最快的收集日是哪天 |

**回國前一個月就要預約。** 三月、九月是搬家旺季，收集日常常排到兩三週後。冷氣、電視、冰箱、洗衣機屬於家電回收對象，不能當大型垃圾，要找電器行或回收業者。

## 台灣人常卡住的地方

1. **台灣是垃圾車來了才丟，日本是放到集中處。** 不用等垃圾車，但一定要在規定時間內、放在規定的地點，不能放在自己家門口。
2. **「洗乾淨」是真的要洗。** 便當盒、優格杯、寶特瓶沒洗過就丟資源垃圾，常被退回。
3. **指定垃圾袋是付費的。** 部分城市（例如京都、福岡、札幌）規定要用付費的指定袋，一般塑膠袋不會被收走。超市、便利商店、藥妝店都買得到。
4. **退租前也要把垃圾處理完。** 留在房間裡的垃圾會被當成清潔費從押金扣掉，退租流程可以參考下面的延伸閱讀。
