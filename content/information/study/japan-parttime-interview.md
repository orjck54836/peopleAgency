在日本找打工，看到喜歡的職缺不難，難的是下一步：**打電話**。

很多徵才廣告寫著「まずはお電話ください」（請先來電），電話一接通就是一連串的日文，緊張起來連自己的名字都說不清楚。面試也一樣，問題其實很固定，**先準備好答案，就不會被問倒**。

這篇照順序整理：打電話應徵、準備履歷、面試問答、錄取之後。

## 二、打電話應徵的完整對話

打電話前，把**職缺名稱、在哪裡看到、自己能上班的時段**寫在紙上。避開午餐（11〜14 點）和晚餐（17〜20 點）的尖峰時段，店家比較有空接。

| 誰說 | 日文 | 讀音 | 意思 |
|------|------|------|------|
| 店 | お電話ありがとうございます。〇〇店です | おでんわありがとうございます。〇〇てんです | 感謝來電，這裡是〇〇店 |
| 你 | お忙しいところすみません。アルバイトの募集を見てお電話しました | おいそがしいところすみません。アルバイトのぼしゅうをみておでんわしました | 抱歉在您忙的時候打擾，我看到打工的徵才資訊所以打來 |
| 你 | 〇〇と申します。採用のご担当者様はいらっしゃいますか | 〇〇ともうします。さいようのごたんとうしゃさまはいらっしゃいますか | 我叫〇〇，請問負責招募的人在嗎 |
| 店 | 少々お待ちください | しょうしょうおまちください | 請稍等 |
| 店 | どちらで募集をご覧になりましたか | どちらでぼしゅうをごらんになりましたか | 您是在哪裡看到徵才的 |
| 你 | タウンワークで拝見しました | タウンワークではいけんしました | 我是在 Townwork 上看到的 |
| 店 | 面接はいつがよろしいですか | めんせつはいつがよろしいですか | 面試什麼時候方便 |
| 你 | 平日の午後でしたら、いつでも大丈夫です | へいじつのごごでしたら、いつでもだいじょうぶです | 平日下午的話，什麼時候都可以 |
| 店 | では、〇日の十五時はいかがですか | では、〇にちのじゅうごじはいかがですか | 那〇號下午三點如何 |
| 你 | はい、大丈夫です。持ち物は何が必要ですか | はい、だいじょうぶです。もちものはなにがひつようですか | 好的，沒問題。需要帶什麼東西 |
| 你 | 〇日の十五時ですね。よろしくお願いいたします | 〇にちのじゅうごじですね。よろしくおねがいいたします | 〇號下午三點對吧，麻煩您了 |

**最後一定要複誦日期和時間。** 日文的數字聽錯很常見，「四時（よじ）」和「七時（しちじ）」尤其容易混。

## 三、打工用的履歷書怎麼寫

便利商店、百圓商店都有賣打工用的履歷書，也有網站可以線上填好列印。重點：

| 欄位 | 怎麼寫 |
|------|------|
| 照片 | 3×4 公分，三個月內拍的，不要用生活照 |
| 姓名 | 漢字照在留卡寫，**ふりがな**用片假名或平假名標讀音 |
| 學歷 | 寫台灣的高中、大學，加上現在就讀的日本語學校（在学中） |
| 資格 | 日檢級數寫「日本語能力試験 N3 合格」 |
| 志望動機 | 兩三行就好，例如「接客を通して日本語を上達させたい」 |
| 本人希望欄 | 寫可以上班的時段，加上「留学生のため、週28時間以内で勤務を希望します」 |

**日期一律寫年號或西元，整份統一。** 寫錯用修正液會被扣分，重寫一張比較好。

## 四、面試常見問題與回答

| 問題 | 日文 | 回答例 |
|------|------|------|
| 自我介紹 | 簡単に自己紹介をお願いします | 台湾から来た〇〇です。今、〇〇日本語学校で勉強しています。どうぞよろしくお願いいたします |
| 應徵動機 | どうしてうちの店を選びましたか | 学校から近くて、日本語を使う機会が多い仕事をしたいと思いました |
| 經驗 | アルバイトの経験はありますか | 台湾でカフェのアルバイトを一年していました |
| 日文程度 | 日本語はどのくらい話せますか | 日常会話は大丈夫です。今、N3 の勉強をしています |
| 排班 | 週に何日くらい入れますか | 週に三日、一日五時間くらい入れます |
| 時段 | 何曜日の何時から入れますか | 月曜と水曜は十四時から、土曜は一日入れます |
| 打工許可 | 資格外活動許可は持っていますか | はい、在留カードの裏に記載があります |
| 長期 | いつまで日本にいる予定ですか | 来年の三月まで日本語学校に通い、そのあと専門学校に進学する予定です |
| 反問 | 何か質問はありますか | 研修はどのくらいありますか／制服はありますか |

**「什麼時候都可以」在打工面試是加分。** 但不要答應超過每週 28 小時的排班，被發現超時，影響的是你自己的簽證續簽。

說不出完整句子時，可以用：

| 日文 | 讀音 | 意思 |
|------|------|------|
| すみません、もう一度お願いします | すみません、もういちどおねがいします | 不好意思，請再說一次 |
| もう少しゆっくり話していただけますか | もうすこしゆっくりはなしていただけますか | 可以說慢一點嗎 |
| 〇〇という意味ですか | 〇〇といういみですか | 是〇〇的意思嗎 |

## 五、錄取之後與不錄取時

| 情境 | 日文 | 讀音 | 意思 |
|------|------|------|------|
| 錄取 | ありがとうございます。精一杯頑張ります | ありがとうございます。せいいっぱいがんばります | 謝謝，我會盡全力 |
| 問第一天 | 初日は何時に、どこに行けばいいですか | しょにちはなんじに、どこにいけばいいですか | 第一天幾點要到哪裡 |
| 問準備 | 持っていくものはありますか | もっていくものはありますか | 有需要帶的東西嗎 |
| 辭退 | 大変申し訳ないのですが、今回は辞退させていただきます | たいへんもうしわけないのですが、こんかいはじたいさせていただきます | 非常抱歉，這次我想辭退 |
| 不錄取 | わかりました。お時間をいただき、ありがとうございました | わかりました。おじかんをいただき、ありがとうございました | 了解了，謝謝您撥時間 |

**同時應徵好幾家很正常**，決定好要去哪家之後，記得打電話跟其他錄取你的店家辭退，不要直接不回應。

## 台灣人常卡住的地方

1. **還沒拿到資格外活動許可就去應徵。** 在機場入境時可以申請，或之後到入管局申請。在留卡背面沒有許可的記載，店家不能雇用你。
2. **遲到。** 日本的面試要提早 5〜10 分鐘到，但也不要太早，太早到可以先在附近等。真的會遲到，一定要事先打電話。
3. **穿著太隨便。** 打工面試不用穿西裝，但要乾淨整齊，不要穿拖鞋、短褲。
4. **把「はい」當成「我聽懂了」。** 聽不懂就直接問，答錯排班時段或上班日期，比當場問一次更麻煩。

---

面試的問題就那幾題，但第一次被店長面對面問時，腦袋常常一片空白。在皓學日語 App 的「打工面試」主題裡，AI 會扮演店長，從打電話應徵到面試問答都可以模擬，你可以用說的把自我介紹、排班時段練到順口。
