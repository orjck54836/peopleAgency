決定去日本留學之後，找房子是最讓人頭痛的事之一。

不只是要看懂租屋廣告上密密麻麻的漢字，還要和仲介、房東溝通——光是這樣就足以讓很多人打退堂鼓。

其實只要先認識幾個核心單字，你會發現日本的租屋流程其實非常有規律，完全可以掌握。

---

## 一、租屋廣告常見單字

看懂廣告是第一關，以下是出現頻率最高的詞彙：

| 日文 | 讀音 | 意思 |
|------|------|------|
| 賃貸 | ちんたい | 租賃（出租房屋） |
| 家賃 | やちん | 月租金 |
| 管理費 | かんりひ | 管理費（每月額外收取） |
| 敷金 | しききん | 押金（退租時可退還） |
| 礼金 | れいきん | 謝禮金（不退還，給房東的禮金） |
| 仲介手数料 | ちゅうかいてすうりょう | 仲介費 |
| 築年数 | ちくねんすう | 屋齡（幾年的房子） |
| 間取り | まどり | 房間格局 |
| 専有面積 | せんゆうめんせき | 室內坪數 |
| 駅徒歩〇分 | えきとほ〇ふん | 距車站步行幾分鐘 |

## 二、房型格局怎麼看？

日本的房型用「LDK」系統標示，初來乍到很容易看不懂：

| 標示 | 意思 |
|------|------|
| 1R | 一房（無隔間，廚房與房間同一空間） |
| 1K | 一房一廚（廚房與房間有隔間） |
| 1DK | 一房＋飯廳廚房 |
| 1LDK | 一房＋客廳飯廳廚房 |
| 2LDK | 兩房＋客廳飯廳廚房 |

留學生預算有限，通常會選 **1K 或 1R**，月租約 3 萬～6 萬日圓（依城市而異）。

## 三、費用相關單字

| 日文 | 讀音 | 意思 |
|------|------|------|
| 初期費用 | しょきひよう | 入住初期費用（押金＋禮金＋仲介費等加總） |
| 前払い家賃 | まえばらいやちん | 預付房租（通常需付 1～2 個月） |
| 保証人 | ほしょうにん | 保證人 |
| 保証会社 | ほしょうがいしゃ | 保證公司（無保證人時可用） |
| 火災保険 | かさいほけん | 火險（通常強制購買） |
| 更新料 | こうしんりょう | 續約金（合約到期續租時支付） |
| 解約 | かいやく | 解約、退租 |
| 退去 | たいきょ | 搬出、退房 |

> 皓學合作的學生宿舍與租屋網絡，**免保證人**，幫你省去找保證人的麻煩。

## 四、設備與條件單字

| 日文 | 讀音 | 意思 |
|------|------|------|
| エアコン | — | 冷暖氣 |
| 洗濯機置き場 | せんたくきおきば | 洗衣機放置處 |
| バス・トイレ別 | — | 浴室與廁所分開（較受歡迎） |
| オートロック | — | 自動門鎖（較安全） |
| 宅配ボックス | たくはいボックス | 包裹代收箱 |
| ペット可 | ペットか | 允許養寵物 |
| 外国人可 | がいこくじんか | 允許外國人承租 |

找房時記得確認是否標示「**外国人可**」或「**留学生可**」，避免白跑一趟。

## 五、與仲介或房東溝通常用句

**看房時：**

```
この部屋を見せていただけますか？
（kono heya wo misete itadakemasu ka）
可以讓我看一下這間房間嗎？
```

```
家賃の交渉はできますか？
（yachin no kōshō wa dekimasu ka）
租金可以議價嗎？
```

```
いつから入居できますか？
（itsu kara nyūkyo dekimasu ka）
最快什麼時候可以入住？
```

**確認設備時：**

```
インターネットは使えますか？
（intānetto wa tsukaemasu ka）
這裡有網路可以用嗎？
```

```
エアコンはついていますか？
（eakon wa tsuite imasu ka）
有附冷暖氣嗎？
```

**簽約時：**

```
契約書を確認させてください。
（keiyakusho wo kakunin sasete kudasai）
請讓我確認一下合約。
```

```
敷金は退去時に返ってきますか？
（shikikin wa taikyo ji ni kaette kimasu ka）
押金退租時可以退還嗎？
```

## 留學生找房的實用小提示

1. **提早準備** — 熱門城市（東京、大阪）的學生宿舍名額有限，入學前 3 個月就要開始詢問。
2. **確認外國人可入住** — 部分房東不接受外國租客，找房前先確認。
3. **善用學校介紹** — 語言學校通常有合作宿舍或租屋資源，是最省事的起點。
4. **了解初期費用** — 日本租屋初期費用往往是月租的 4～6 倍，要提前準備好預算。
