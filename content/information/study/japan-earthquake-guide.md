在日本住一段時間，一定會遇到地震。多數是搖一下就停的小地震，但**手機突然發出警報聲**的那一刻，第一次遇到的人通常會愣住。

台灣也有地震，所以大部分人不會太慌。真正會卡住的，是**聽不懂警報和新聞在說什麼**、不知道避難所在哪、不知道該怎麼跟周圍的日本人溝通。

這篇照時間順序整理：地震前的準備、搖晃時、搖晃後、去避難所，每一段用得到的日文。

## 一、先看懂這些字

| 日文 | 讀音 | 意思 |
|------|------|------|
| 地震 | じしん | 地震 |
| 揺れ | ゆれ | 搖晃 |
| 震度 | しんど | 震度（各地感受到的搖晃程度） |
| マグニチュード | マグニチュード | 規模（地震本身的大小） |
| 震源 | しんげん | 震源 |
| 余震 | よしん | 餘震 |
| 緊急地震速報 | きんきゅうじしんそくほう | 緊急地震速報（手機警報） |
| 津波 | つなみ | 海嘯 |
| 避難 | ひなん | 避難 |
| 避難所 | ひなんじょ | 避難所 |
| 避難場所 | ひなんばしょ | 避難場所（臨時集合的空地、公園） |
| 停電／断水 | ていでん／だんすい | 停電／停水 |
| ハザードマップ | ハザードマップ | 防災地圖 |

**「避難所」和「避難場所」不一樣。** 避難場所是先跑去躲的公園、空地，避難所是可以待一段時間、有物資的地方（通常是學校體育館）。

## 二、日本的震度怎麼看

| 震度 | 大概的感覺 |
|------|------|
| 1〜2 | 室內靜止的人才感覺得到 |
| 3 | 大部分的人都感覺得到，餐具會響 |
| 4 | 睡著的人會醒，吊燈大幅搖晃 |
| 5弱 | 會想抓住東西，架上的東西掉下來 |
| 5強 | 很難走路，沒固定的家具可能倒下 |
| 6弱 | 站不穩，門可能打不開 |
| 6強〜7 | 無法站立，老舊房屋可能倒塌 |

新聞會說「**〇〇市で震度5弱を観測しました**」（〇〇市觀測到震度 5 弱）。**要看的是自己所在地區的震度**，規模是地震本身的大小，和你家搖得多大不是同一件事。

## 三、手機警報與新聞會說什麼

緊急地震速報響起時，手機會發出很特別的警報聲，畫面出現這幾句：

| 日文 | 讀音 | 意思 |
|------|------|------|
| 緊急地震速報 | きんきゅうじしんそくほう | 緊急地震速報 |
| 強い揺れに備えてください | つよいゆれにそなえてください | 請準備迎接強烈搖晃 |
| 落ち着いて身の安全を確保してください | おちついてみのあんぜんをかくほしてください | 請冷靜，確保自身安全 |
| 津波警報が発表されました | つなみけいほうがはっぴょうされました | 已發布海嘯警報 |
| ただちに高台に避難してください | ただちにたかだいにひなんしてください | 請立刻往高處避難 |
| この地震による津波の心配はありません | このじしんによるつなみのしんぱいはありません | 這次地震沒有海嘯疑慮 |

**聽到「津波」兩個字就要特別注意。** 住在海邊或河口附近，海嘯警報一出來就往高處走，不要等確認，也不要去海邊看。

## 四、搖晃時與搖晃後

搖晃的時候：

1. **保護頭部**，躲到桌子底下，或遠離書櫃、窗戶、冰箱
2. **不要急著往外跑**，外面有招牌、玻璃掉落
3. 在電車上抓好吊環或扶手，聽廣播指示，不要自己打開車門
4. 在超市或商場，用包包護住頭，遠離貨架

搖晃停止後：

1. 關掉瓦斯、拔掉電器插頭，**停電後恢復供電時可能起火**（通電火災）
2. 打開門窗確保出口，穿上鞋子（地上可能有碎玻璃）
3. 用電視、廣播、手機確認資訊，**不要聽信沒有來源的傳言**
4. 有危險、或房子受損時才去避難所，平安的話待在家裡也可以（在宅避難）

## 六、在避難所會聽到的句子

| 日文 | 讀音 | 意思 |
|------|------|------|
| こちらで受付をしてください | こちらでうけつけをしてください | 請在這裡登記 |
| お名前と住所を書いてください | おなまえとじゅうしょをかいてください | 請寫下姓名和住址 |
| 配給は十二時からです | はいきゅうはじゅうにじからです | 物資發放從十二點開始 |
| 一人一つまでです | ひとりひとつまでです | 每人限一個 |
| 土足禁止です | どそくきんしです | 禁止穿鞋進入 |
| 消灯は九時です | しょうとうはくじです | 九點熄燈 |

**避難所不分國籍，也不用錢。** 登記時寫下名字，之後家人或學校要找你時比較容易確認。

## 七、剛到日本就該準備的東西

| 類別 | 準備什麼 |
|------|------|
| 防災包 | 水（一人一天 3 公升，至少 3 天份）、不用加熱的食物、手電筒、行動電源、常備藥、現金（零錢） |
| 證件影本 | 護照、在留卡的影本或照片，另外存一份在雲端 |
| 家具固定 | 書櫃、冰箱用固定器或伸縮桿固定，床邊不要放會倒的東西 |
| 確認地點 | 用區役所網站或「ハザードマップ」查住處附近的避難所，實際走一次 |
| App | 日本觀光廳的「Safety tips」（有中文，會推播地震與海嘯警報）、NHK WORLD-JAPAN |
| 聯絡方式 | 跟家人約好聯絡方法；學校的緊急聯絡窗口記在手機裡 |

**報平安用「171」。** NTT 的災害用傳言電話在大地震時會開放，撥 171 可以錄音留言，家人用你的電話號碼就能收聽。各電信公司也有網路版的「災害用伝言板」。

## 台灣人常卡住的地方

1. **「台灣常地震，沒差」最危險。** 日本的老舊木造房屋多，耐震條件和台灣的鋼筋水泥大樓不同，租屋時可以問房東「**新耐震基準ですか**」（是新耐震基準的建物嗎，1981 年 6 月以後申請建造的才是）。
2. **警報響了不要先拍影片。** 先保護自己，緊急地震速報到搖晃常常只有幾秒。
3. **假消息很多。** 大地震後社群上會出現各種傳言，以 NHK、氣象廳、市區町村的公告為準。
4. **要讓學校知道你平安。** 語言學校在大地震後會確認學生安危，收到學校的聯絡要盡快回覆。

---

地震的時候最需要的不是背很多單字，而是聽得懂、說得出口。在皓學日語 App 的「地震」主題裡，AI 會扮演避難所的工作人員或同棟的鄰居，跟你模擬地震後的確認、詢問、求助對話，可以用說的反覆練習。
