在日本咖啡廳點餐，說「**ホットコーヒーのMサイズを一つ、店内でお願いします**」（熱咖啡中杯一杯，內用）就能一次點好。店員會問的問題也很固定：內用還是外帶、尺寸、冰的還是熱的。

下面照實際的順序整理：進店、點餐、客製化、找位子和問設備、離開。

## 一、先看懂店裡的字

| 日文 | 讀音 | 意思 |
|------|------|------|
| 店内 | てんない | 內用 |
| 持ち帰り／テイクアウト | もちかえり | 外帶 |
| ホット | ホット | 熱的 |
| アイス | アイス | 冰的 |
| ブレンド | ブレンド | 綜合咖啡（店裡的基本款） |
| カフェラテ | カフェラテ | 拿鐵 |
| 紅茶 | こうちゃ | 紅茶 |
| モーニング | モーニング | 早餐套餐 |
| セット | セット | 套餐 |
| 返却口 | へんきゃくぐち | 餐具回收處 |
| 禁煙／喫煙 | きんえん／きつえん | 禁菸／吸菸 |

連鎖咖啡廳多半是「先在櫃台點餐付錢，再自己端去座位」。老派的喫茶店（きっさてん）則是先入座，店員會過來點餐，離開時到櫃台結帳。

## 二、櫃台點餐

| 誰說 | 日文 | 讀音 | 意思 |
|------|------|------|------|
| 店員 | いらっしゃいませ。ご注文をどうぞ | いらっしゃいませ。ごちゅうもんをどうぞ | 歡迎光臨，請點餐 |
| 店員 | 店内でお召し上がりですか | てんないでおめしあがりですか | 請問是內用嗎 |
| 你 | はい、店内で | はい、てんないで | 對，內用 |
| 你 | 持ち帰りでお願いします | もちかえりでおねがいします | 我要外帶 |
| 你 | カフェラテを一つお願いします | カフェラテをひとつおねがいします | 一杯拿鐵 |
| 店員 | サイズはいかがなさいますか | サイズはいかがなさいますか | 請問要什麼尺寸 |
| 你 | Mサイズでお願いします | エムサイズでおねがいします | 中杯 |
| 店員 | ホットとアイス、どちらになさいますか | ホットとアイス、どちらになさいますか | 請問要熱的還是冰的 |
| 你 | アイスでお願いします | アイスでおねがいします | 冰的 |
| 店員 | ご注文は以上でよろしいですか | ごちゅうもんはいじょうでよろしいですか | 請問這樣就好了嗎 |
| 你 | はい、以上です | はい、いじょうです | 對，就這樣 |

不知道怎麼唸品項的話，指著菜單說「**これを一つお願いします**」（這個一份）就可以。想請店員推薦可以問「**おすすめは何ですか**」。

## 三、客製化

| 日文 | 讀音 | 意思 |
|------|------|------|
| 氷少なめでお願いします | こおりすくなめでおねがいします | 少冰 |
| 氷なしでお願いします | こおりなしでおねがいします | 去冰 |
| 豆乳に変更できますか | とうにゅうにへんこうできますか | 可以換成豆漿嗎 |
| ミルクを多めにしてください | ミルクをおおめにしてください | 牛奶請多一點 |
| シロップは抜いてください | シロップはぬいてください | 請不要加糖漿 |
| ホイップなしでお願いします | ホイップなしでおねがいします | 不要鮮奶油 |
| ショットを追加してください | ショットをついかしてください | 請加一份濃縮 |
| カフェインレスはありますか | カフェインレスはありますか | 有低咖啡因的嗎 |
| 砂糖とミルクをください | さとうとミルクをください | 請給我糖和奶精 |

店員也可能反過來問你「**お砂糖とミルクはご利用ですか**」（需要糖和奶精嗎），要就回「お願いします」，不用就回「大丈夫です」。

## 四、找位子、問插座和 Wi-Fi

| 日文 | 讀音 | 意思 |
|------|------|------|
| この席、空いていますか | このせき、あいていますか | 這個位子有人坐嗎 |
| コンセントは使えますか | コンセントはつかえますか | 可以用插座嗎 |
| コンセントのある席はどこですか | コンセントのあるせきはどこですか | 有插座的位子在哪裡 |
| Wi-Fi はありますか | ワイファイはありますか | 有 Wi-Fi 嗎 |
| Wi-Fi のパスワードを教えてください | ワイファイのパスワードをおしえてください | 請告訴我 Wi-Fi 密碼 |
| パソコンを使ってもいいですか | パソコンをつかってもいいですか | 可以用筆電嗎 |
| お手洗いはどこですか | おてあらいはどこですか | 洗手間在哪裡 |
| 禁煙席をお願いします | きんえんせきをおねがいします | 麻煩給我禁菸席 |

尖峰時段有些店會貼「**お席のご利用は90分まで**」（座位限用 90 分鐘）或「**混雑時は長時間のご利用をご遠慮ください**」（人多時請勿久坐），看到的話就別在那裡工作一整個下午。

## 五、喫茶店入座點餐與結帳

| 誰說 | 日文 | 讀音 | 意思 |
|------|------|------|------|
| 店員 | お好きな席へどうぞ | おすきなせきへどうぞ | 請隨意入座 |
| 你 | すみません、注文お願いします | すみません、ちゅうもんおねがいします | 不好意思，我要點餐 |
| 你 | モーニングはまだやっていますか | モーニングはまだやっていますか | 早餐套餐還有供應嗎 |
| 你 | ケーキセットを一つお願いします | ケーキセットをひとつおねがいします | 一份蛋糕套餐 |
| 你 | おかわりはできますか | おかわりはできますか | 可以續杯嗎 |
| 你 | お会計お願いします | おかいけいおねがいします | 麻煩結帳 |
| 你 | ごちそうさまでした | ごちそうさまでした | 謝謝招待 |

桌上夾著帳單（伝票，でんぴょう）的店，吃完把帳單拿到門口櫃台付錢就好，不用在座位上等。

## 台灣人常卡住的地方

1. **先佔位再點餐不一定可以**。有些店歡迎先放東西佔位，有些店門口會寫「ご注文後にお席をお取りください」（請點餐後再找位子）。貴重物品不要拿來佔位。
2. **沒有「半糖」這種選項**。日本的咖啡廳不幫你調甜度，冰飲的糖漿（ガムシロップ）和奶精放在櫃台旁邊自己拿。
3. **內用外帶要先講清楚**。稅率不同，店員每次都會問。外帶之後臨時想坐下來，要跟店員說一聲。
4. **用完的杯盤要自己收**。自助式的店有「返却口」，托盤和杯子拿過去放就可以，垃圾也在那裡分類。
5. **吸菸席還存在**。老喫茶店和部分連鎖店有吸菸區或整間可吸菸，門口會標示，不喜歡菸味的話進門前先看一眼。
